\chapter{More Than Two Voices}

Binary duality gives two local views of one conversation. A three-party protocol introduces a different problem: each role sees only part of the conversation, yet the local pieces must fit one global causal story. Multiparty session types address that gap with global descriptions and projection.

\section{A finite choreography}
For the bounded \texttt{PROTO-M1} layer, a global description is a finite tree of interactions
\[
p\to q : \ell(A);\;G
\]
and labeled branches. It is a specification artifact, not a runtime orchestrator. Projection $\proj{G}{p}$ extracts the local obligations relevant to role $p$ when the finite choreography satisfies the simple projectability conditions used here.

\section{Projection example}
Consider three roles: client $C$, broker $B$, worker $W$.
\[
C\to B:\mathsf{job}(\Nat);
\quad
B\to W:\mathsf{job}(\Nat);
\quad
W\to B:\mathsf{result}(\Bool);
\quad
B\to C:\mathsf{result}(\Bool).
\]
Projection gives $C$ only its exchange with $B$, $W$ only its exchange with $B$, and $B$ the four-step local sequence. The global ordering explains how these local views are intended to compose.

\section{Exemplar trace theorem}
\begin{proposition}[T4.16, projection trace preservation for the registered finite exemplars]
For each acyclic choreography registered in Lab 09, exhaustive enumeration of its finite branch choices yields the same role-labeled communication traces as the synchronized composition of its projected local types after hiding projection bookkeeping.
\end{proposition}
\begin{proof}
This is a finite per-exemplar result, not a general MPST theorem. Lab 09 enumerates every branch path of each registered choreography, projects each role, then reconstructs all synchronized local traces. Equality of the two finite trace sets is checked exhaustively and retained as machine-readable evidence.
\end{proof}

\section{Where projection can fail}
If one role's next behavior depends on a branch chosen elsewhere but no message reveals that choice, its local projection is ambiguous. More generally, realizability and projectability impose global conditions. T4.17, general multiparty projection correctness, is imported only when a cited external theorem's exact hypotheses are stated; it is not re-proved by this monograph.

\section{Do not confuse: a global type with a central controller}
\begin{warningbox}
A choreography describes a global protocol. It does not imply a runtime component that observes or schedules every event. Whether projected peers realize the global description is a theorem question, not an architectural diagram.
\end{warningbox}
