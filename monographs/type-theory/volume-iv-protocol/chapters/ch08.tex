\chapter{Messages in Flight}

Synchronous communication treats a send and its matching receive as one rendezvous. Real systems often buffer messages. Once a send can complete before the peer receives, the queue is part of the semantic state. The proof obligations change with it.

\section{Configurations include queues}
A bounded \texttt{PROTO-A1} configuration is written schematically as
\[
\langle P,Q;\;q_{xy},q_{yx}\rangle.
\]
A send appends a typed message to the appropriate FIFO queue. A receive consumes the oldest compatible message. Endpoint session states and queue contents must therefore be typed together.

\section{Queue typing invariant}
\begin{definition}[Queue-consistency frontier]
For the teaching fragment, a queue is consistent with a sender/receiver pair when its messages are exactly a finite prefix of outputs already consumed by the sender's local session state but not yet consumed by the receiver's local state, in FIFO order and with the declared payload/label classes.
\end{definition}
\begin{theorem}[T4.13, finite asynchronous queue invariant]
If a bounded \texttt{PROTO-A1} configuration is queue-consistent and takes one enqueue or dequeue step, the resulting configuration is queue-consistent under the corresponding endpoint-state evolution.
\end{theorem}
\begin{proof}
By cases on the step. Enqueue appends exactly the message class required by the sender's next output and advances only the sender frontier, extending the pending prefix by one. Dequeue requires the queue head to match the receiver's next input and removes exactly that head while advancing the receiver frontier. FIFO order is preserved in both cases.
\end{proof}

\section{Asynchronous fidelity}
\begin{theorem}[T4.14, bounded asynchronous fidelity]
For the finite queue-aware fragment defined above, a well-typed configuration that takes one asynchronous reduction remains well typed under the evolved endpoint and queue state.
\end{theorem}
\begin{proof}
Combine T4.13 with the finite prefix typing rules. Process-local continuation typing is preserved exactly as in T4.4; the difference is that sender and receiver frontiers need not advance in the same operational step. The queue-consistency judgment records the gap.
\end{proof}

\section{Not the same trace semantics}
A synchronous handshake yields one joint event. An asynchronous run may expose separate enqueue and dequeue events and intermediate queue states. For selected finite examples we can erase queue-internal steps and compare visible communication traces, but T4.15 is deliberately not a universal equivalence theorem.

\section{Orphans and growth}
If the model permits a peer to terminate while messages remain queued, those messages are orphaned. If queues are unbounded, resource consumption becomes a semantic and systems concern beyond finite type fidelity. The lab makes both states visible rather than silently assuming them away.

\section{Do not confuse: FIFO as reality}
\begin{warningbox}
FIFO is an explicit assumption of \texttt{PROTO-A1}. Networks, brokers, retries, and replicated transports may reorder, duplicate, or lose messages. Those behaviors require a different semantics; they cannot be ``covered'' by leaving the queue model implicit.
\end{warningbox}
