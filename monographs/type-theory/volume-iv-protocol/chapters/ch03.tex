\chapter{Say It, Then Continue}

A communication step is useful only if the static account survives it. The sender consumes one output obligation; the receiver consumes the matching input obligation; both continuations must remain typable under the advanced session environment. This is the interactive analogue of preservation, but the object being preserved is not a closed term type. It is a relation between process state and protocol state.

\section{The commuting obligation}
Write the principal redex as
\[
(\nu x\,y)(x!\chanval{v}.P \mid y?(z).Q)
\to
(\nu x\,y)(P\mid Q[v/z]).
\]
If the endpoint types are $\send{A}{S}$ and $\recv{A}{\dual S}$, then the protocol frontier must advance to $S$ and $\dual S$. We therefore track a process step and an environment step together:
\[
P\to P',\qquad \Delta\envstep\Delta'.
\]
The preservation question is whether $\ptypes{\Gamma}{\Delta}{P}$ implies $\ptypes{\Gamma}{\Delta'}{P'}$ for the exact reduction cases admitted by the calculus.

\section{Payload substitution}
\begin{lemma}[T4.3, payload substitution]
In the first-order payload layer of \texttt{PROTO-0}, if $\Gamma,z:A\vdash e:B$ and $\Gamma\vdash v:A$, then $\Gamma\vdash e[v/z]:B$.
\end{lemma}
\begin{proof}
By structural induction on the payload expression $e$. Variables are the critical case: $z[v/z]=v$, while every other variable keeps its typing assumption. Pair, injection, and primitive-elimination cases follow from the induction hypotheses. Capture avoidance is immediate for the first-order fragment; if binders are added to the payload language, the ordinary alpha-renaming side condition is required.
\end{proof}

\section{Principal communication}
\begin{proposition}[Send/receive preservation kernel]
Suppose
\[
\ptypes{\Gamma}{\Delta,x:\send{A}{S},y:\recv{A}{\dual S}}
{(\nu x\,y)(x!\chanval{v}.P\mid y?(z).Q)}
\]
with $\Gamma\vdash v:A$. Then the principal step is typable under the environment obtained by replacing those two bindings by $x:S$ and $y:\dual S$.
\end{proposition}
\begin{proof}
Invert the output and input typing derivations. The sender continuation is typed under $x:S$; the receiver continuation is typed under $y:\dual S$ and $z:A$. Apply T4.3 to $Q$ using $\Gamma\vdash v:A$. The parallel rule then reconstructs the post-step process with the same disjoint split except for the advanced endpoint bindings.
\end{proof}

\section{Worked example}
\begin{workedexample}
For $S=\send{\Nat}{\recv{\Bool}{\mathsf{end!}}}$, a transfer of $7$ changes the client obligation from $!\Nat.? \Bool.\mathsf{end!}$ to $?\Bool.\mathsf{end!}$ and the service obligation from its dual to $!\Bool.\mathsf{end?}$. The integer $7$ is substituted only in the receiver continuation. No liveness conclusion follows from this one step.
\end{workedexample}

\section{Do not confuse: preservation with availability}
\begin{warningbox}
Preservation is conditional: \emph{if} a typed process takes a reduction step, the result remains typed under the advanced protocol state. It does not say that a reduction step exists. Availability is a progress question, and global availability is stronger still.
\end{warningbox}
