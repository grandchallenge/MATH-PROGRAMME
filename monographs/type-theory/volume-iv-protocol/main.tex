\chapter*{Scope and series thesis}
The phrase ``grand unified theory'' names a research thesis, not an established theorem.
This volume asks what changes when the primary computational object is interaction rather than
closed function evaluation.

The present Gate-1 teaching kernel develops only a finite synchronous binary session calculus.
It establishes the vocabulary and executable evidence needed for later chapters. It does not
establish arbitrary deadlock freedom, fairness, fault tolerance, security, asynchronous
correctness, or distributed-system correctness.

\chapter*{How to read the formalism}
A session type is an ordered communication obligation. A typing judgment
\[
  \ptypes{\Gamma}{\Delta}{P}
\]
separates reusable value assumptions in \(\Gamma\) from linear channel obligations in
\(\Delta\). The distinction is essential: the calculus is designed so that two parallel
subprocesses cannot independently consume the same linear endpoint obligation.

\chapter*{Gate-1 transition}
The first two chapters establish the smallest executable protocol kernel. The next chapter must
prove that a well-typed communication step advances process state and session state together.
Later chapters will then deliberately construct a locally well-typed multi-session deadlock to
separate session fidelity from global liveness.
