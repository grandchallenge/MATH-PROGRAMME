# MATHFORGE + MATHSOLVE + MATHCERT

## Programme-grade specification pack

This package replaces the earlier seed scaffold with a Grand-Challenge-style programme standard. It is organized around three distinct but interlocking functions:

- **MATHFORGE** discovers, reconstructs, clusters, searches, and generates candidate mathematics.
- **MATHSOLVE** conducts the mathematical campaign: status spines, reductions, Work Packages, failed attempts, partial theorems, exact screens, synthesis manuscripts, and certification handoffs.
- **MATHCERT** certifies what survives: Lean/equivalent formalization, exact rational ledgers, interval certificates, SAT/SMT proof artifacts, CI gates, and claim classification.

The core distinction is simple:

> MATHFORGE may be imaginative. MATHSOLVE must be disciplined. MATHCERT must be unforgiving.

This pack is designed to embody the Grand-Challenge style cultivated in the Chaidez programme: lay companion, formal theorem spine, claim ledger, proof/computation boundary, negative-result accounting, exact next target, and certification route.

## How to use this pack

1. Read `ARCHITECTURE_OVERVIEW.md` first.
2. Read the three pillar specifications.
3. Apply `GRAND_CHALLENGE_WORK_PACKAGE_STANDARD.md` to every MATHSOLVE Work Package.
4. Treat `CLAIM_LEDGER_STANDARD.md` as binding. No claim should appear without a type, support route, and promotion condition.
5. Treat `CERTIFICATION_LADDER.md` as the promotion gate from mathematical development to certified result.
6. Begin the first domain with `DOMAIN_01_UNION_CLOSED_MASTER_PLAN.md`, `WP01_UNION_CLOSED_STATUS_SPINE.md`, and `WP02_UNION_CLOSED_LEAN_HANDOFF.md`.

## Claim boundary

This package does not claim new mathematical results. The included Union-Closed enumerator is a small exact sanity audit for universes up to size 4. It is useful infrastructure, not progress on Frankl's conjecture.

## Source posture

This pack uses current public sources for context and cites them in the source notes. The programme standard remains stricter than source citation: a source can motivate a claim, but MATHCERT determines whether a claim is checkable.
