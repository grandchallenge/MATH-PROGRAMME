# RH-WP01 — False-proof atlas

Campaign `RH-001`; state `INTERNAL_REVIEW_COMPLETE_REPOSITORY_REVIEW_REQUIRED`.

WP01 is an executable semantic firewall. It turns the twenty seeds `RH-F001`–`RH-F020` into minimal fixtures that identify the first invalid inference, the missing obligation, an exact countermodel or failed hypothesis, the narrowest repair, and what the failure does not rule out.

The atlas covers:

- finite-height and density-to-universality promotion;
- symmetry-to-location and Euler-product continuation errors;
- conditionally convergent sums, logarithm branches, contour residues, and unjustified limit exchanges;
- incomplete positivity and spectral interfaces;
- finite Li, prime-error, Mertens-epsilon, GRH-transfer, simplicity, and zero-free-region quantifier drift;
- uncertified Rouché and floating-point root claims;
- local order errors in the completed function.

Run:

```bash
python campaigns/riemann_hypothesis/WP01_FALSE_PROOF_ATLAS/replay.py
```

A triggered fixture requires rejection or explicit narrowing. Passing every fixture is not evidence for RH and does not certify any proposed route.
