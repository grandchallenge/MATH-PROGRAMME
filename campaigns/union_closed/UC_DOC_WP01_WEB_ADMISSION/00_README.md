## Formal problem statement and scope

For every finite nonempty union-closed family $\mathcal F$, the target is

$$\exists x\in\operatorname{supp}(\mathcal F),\qquad 2\operatorname{freq}_{\mathcal F}(x)\ge |\mathcal F|.$$

The web edition is a derivative presentation. It cannot strengthen `DOMAIN_01_UNION_CLOSED_MASTER_PLAN.md`, the UC-DOC-WP00 source lock, imported literature, Lean theorem statements, or exact certificate scopes.
