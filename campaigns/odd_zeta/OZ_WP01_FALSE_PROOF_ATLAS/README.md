# OZ-WP01 — Executable false-proof atlas

This package turns recurrent invalid inferences in the odd-zeta intake into deterministic claim-packet tests.

## Coverage

The atlas contains six positive controls and sixteen rejected false-proof packets across:

- Apéry harmonic B-row congruences;
- abstract and concrete Theorem-LB claims;
- Brown–Zudilin compact forms and recurrence claims;
- sharp-12 denominator claims;
- novelty and priority claims;
- irrationality bridges;
- zeta(7) operator reconstruction;
- the finite Zudilin disjunction.

## Replay

```bash
python3 campaigns/odd_zeta/OZ_WP01_FALSE_PROOF_ATLAS/replay.py
```

A rejected packet means that its evidence does not support its requested status. It does not, by itself, prove that the mathematical conclusion is false.

## Gate

Successful exact-head replay and repository review close `OZ-WP01` and authorize `OZ-WP02`. No theorem, novelty, Lean, sharp-12, or irrationality promotion occurs.
