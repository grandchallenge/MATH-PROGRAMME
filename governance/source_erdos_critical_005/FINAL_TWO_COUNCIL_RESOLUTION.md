## Exact execution and governance

The new Council module is read-only unless executed in the existing GitHub Actions protected-main workflow with source_scope set to final_two. It requires the restricted GCL Council Clerk App token. The App posts one exact-material source-correction receipt on each parent before changing its review label from gcl-review:revise to gcl-review:source-corrected, and the controller independently verifies both labels and the OPEN / RETURNED custody. Missing evidence, changed source bytes, new axioms, an unrecognized actor, unauthorized runtime, or claimed certification fails closed.

The historical original_three dispatch stays the default and retains its existing controls.
