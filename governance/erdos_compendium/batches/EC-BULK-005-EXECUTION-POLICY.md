# EC-BULK-005 — Execution-tool policy

**Status:** ACTIVE for the EC-BULK-005 coordinator, source workers, editorial review and production workflow. This document adds tool-selection guidance; it does not expand the original task's authority.

## Codex is optional

Codex is **not** a prerequisite, preferred execution bottleneck, or condition for proceeding with ordinary GCL work. Do **not** postpone queue pickup, source audits, primary-source inspection, `RESULT/1` issue comments, article writing, review, reconciliation, validation, production PRs, protected merges or editorial admission because Codex is absent, unconfigured, inactive or unavailable.

Use whatever **authorized and authenticated** path fits the task: GitHub connectors/API and `gh`, CHAD shell, Python, browser-based source inspections, existing GCL workers, and relevant computational runners. Source research and mathematical exposition require evidence and correctness, not a particular agent product.

Reserve Codex for a **specific, justified requirement**, for example a complex multi-file code change, repo-scale refactor, specialized code-navigation task, or a previously approved Codex-specific workflow. Explicitly record such a requirement if it genuinely cannot be satisfied through another permitted path. Do not introduce a Codex dependency solely for convenience or because an earlier workflow mentioned it.

Specialized computation, including Lean on Colab, is similarly task-dependent. It is not necessary for routine editorial exposition; invoke it only where it materially verifies a particular mathematical or computational obligation.

## Requirements that remain mandatory

- Authenticated GitHub worker identity and existing queue-pickup rules; no anonymous or invented worker returns.
- Exact source provenance, `RESULT/1` validation, and critical mathematical/source checking.
- Reproducible finite examples, correct mathematical typography and rendered-site verification.
- Proper separation of source return, manuscript production, editorial acceptance and mathematical certification.
- Existing protected approvals, CI, GitHub merge policy and admission records.

**Blocker rule:** Lack of Codex is not a general blocker. If a genuinely tool-specific capability is unavailable, record precisely why no authorized equivalent can complete that *bounded* task, and continue independent work through available authorized paths.
