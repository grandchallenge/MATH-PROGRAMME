# EC-BULK-007 — #1197 reported 2026 counterexample

**Source-fidelity review PENDING; no independently verified universal theorem refutation claimed.**

The catalogue at https://www.erdosproblems.com/1197 reports an ebarschkis 2026 counterexample based on Buczolich–Mauldin 1999. To refute the precise conjecture, it must provide **one positive-measure measurable set E** and a **positive-measure set of x** for which arbitrarily large integers n admit NO positive integer r with nx/r in E.

If E contains an interval (a,b), the original property holds for every fixed x>0 and all large n, since admissible r lie in (nx/b,nx/a), with length growing linearly. The counterexample therefore cannot be inferred from the easy interval case and needs its detailed construction proof checked, including quantifiers 'almost all x' and 'for all sufficiently large n'.

Phase23 verifies the interval E=(1,2), x=3/2 example only.
