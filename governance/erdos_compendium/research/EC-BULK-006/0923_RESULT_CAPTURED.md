## Exact statement and normalization
For EVERY positive integer k, is there an integer f(k) so that EVERY finite simple graph G with chi(G)>=f(k) contains a TRIANGLE-FREE SUBGRAPH H with chi(H)>=k? YES, Vojtěch Rödl 1977. H means arbitrary subgraph: choose subset of vertices AND SUBSET OF EDGES, NOT necessarily induced. Distinguish an induced triangle-free subgraph: for K_t each nontrivial induced H is clique; triangle-free ones have chi<=2, while large K_t contains arbitrary non-induced triangle-free high-chi examples. Exact >=k vs exactly k are similar for non-induced target but any claimed exact conversion needs proof. Generalized large-girth g>4 conjecture NOT solved by Rödl1977.

## Strongest verified interface
Reconstruct primary paper elementary inductive bound: fix target n>=2. Set phi(2,n)=2, P=phi(m−1,n)−1, phi(m,n)=(n−1)^P+1 for m>=3. Suppose K_m-free G with chi>=phi(m,n) and ordered vertices. Every earlier-neighbor induced graph L(v) has no K_(m−1); if any L(v) has chi>=phi(m−1,n), induction produces trianglefree H chi>=n. Else color each L(v) with <=P colors. For every edge u<v assign bucket i=local color of u in L(v). If triangle x<y<z survived in bucket i, x,y adjacent in L(z) would have same color i, contradiction. Thus P buckets each triangle-free, partition E(G). If each bucket (on ALL original vertices) had chi<=n−1, combine P proper color coordinates, giving chi(G)<=(n−1)^P, contradict threshold; hence some bucket chi>=n. The induction plus known arbitrarily high-chi finite trianglefree graphs completes source theorem.
