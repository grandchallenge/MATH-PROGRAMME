## Exact statement and normalization
Erdős [Er71, p103] asks: for fixed integer k>=4 is ex(n,H_k)=O_k(n^(3/2))? ex(n,H) is maximum edges in an n-vertex simple graph containing NO subgraph isomorphic to H (not necessarily induced). H_k is bipartite incidence graph of lowest 3 levels Boolean lattice B_k: vertex x for empty, branch y_i for each singleton i=1..k, and DISTINCT pair vertex z_{i,j} for EACH unordered i<j; only edges x-y_i and y_i-z_{i,j},y_j-z_{i,j}. Thus v=1+k+choose(k,2), e=k+2choose(k,2)=k², branch degrees k, pair degrees2. Site's abbreviated 'a unique z_i for each pair' must mean one DIFFERENT z per pair; shared pair vertices would alter problem. H_k contains C4 x-y_i-z_{i,j}-y_j-x for any pair. H_k is 2-degenerate via eliminating all z then all y then x, and bipartite.
