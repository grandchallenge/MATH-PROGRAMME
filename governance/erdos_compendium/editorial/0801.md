## The question in plain language

If n-vertex G has independence number alpha(G)<=sqrt n (no independent set larger), then there exists vertex subset S of size <=sqrt n spanning >=c sqrt n log n edges for an absolute positive constant c, for sufficiently large n. Need clarify floors and asymptotic meaning.

**Scope check:** count only edges with both endpoints inside the selected vertex set, not the degrees of selected vertices into the full graph. Asymptotic absolute constants and integer rounding need primary-source verification.

For K9, alpha=1<=3. A 3-vertex subset contains 3 edges, illustrating local density but not estimating the asymptotic constant c. For an empty graph on nine vertices alpha=9, so premise fails. The target is induced edges, not total degrees from the chosen vertices into the rest.
