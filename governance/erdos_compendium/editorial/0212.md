## The question in plain language

Is there a set $S\subseteq\mathbb R^2$ that is **dense in the entire plane**, and for which **every pair of distinct points** is separated by a rational Euclidean distance? Density means every nonempty open disk contains at least one point of $S$; a large or infinite rational-distance set need not be dense.

This is Ulam's rational-distance problem, discussed by Erdős. The condition concerns the **distance itself**, not merely its square, and allows arbitrary real coordinates.

## A small example

A line can contain a dense rational-distance set: take the rational points $(q,0)$ for $q\in\mathbb Q$. Every pair has rational distance $|q-r|$. But that set lies on one line, so it is not dense in the plane.

Similarly, points on an appropriately parametrized circle can have pairwise rational chord lengths in some constructions. Such a set is contained in the circle and is therefore not plane-dense. Finding one large rational-distance configuration does not answer the global problem.

## What is known

**OPEN unconditionally.** Terence Tao and independently Shaffaf established that, **assuming the Bombieri–Lang conjecture**, rational-distance planar sets must lie in a **finite union of real algebraic curves**. Solymosi and de Zeeuw proved unconditionally that a rational-distance set on a real algebraic curve is finite unless the curve contains a line or a circle. Related work by Ascher, Braune and Turchet develops further consequences for sets in general position under the same conjectural assumption.

A finite union of proper real algebraic curves has empty interior and is nowhere dense, so it cannot contain a subset dense in the plane. Thus the conditional structural theorem rules out Ulam's dense set **assuming Bombieri–Lang**. The number-theoretic conjecture is not a proved hypothesis, and the conditional no-go theorem cannot be reported as an unconditional disproof.

The maintained [Erdős #212](https://www.erdosproblems.com/212) attributes the conjecture to Ulam and describes the conditional results.

## What remains

A bounded task enumerates Pythagorean-rational-distance point sets, independently checks rationality of **actual distances**, and tests density predicates only on specified finite grids. Acceptance: rational points on a single line are classified as *not plane-dense*, and conditional proofs retain Bombieri–Lang in the hypotheses. Stop before interpreting arbitrary finite approximation to an open disk as a dense infinite construction.
