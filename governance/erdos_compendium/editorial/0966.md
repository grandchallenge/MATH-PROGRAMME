## The question in plain language

Fix integers \(k,r\ge2\). Is there a subset \(A\subseteq\mathbb N\) with **no nonconstant arithmetic progression of length \(k+1\)**, but such that **every \(r\)-coloring of \(A\)** contains a **monochromatic nonconstant arithmetic progression of length \(k\)**?

**Yes. This is proved.** In fact, \(A\) can be chosen **finite**. Erdős [Er75b] reported in 1975 that Joel Spencer had obtained the result, but gave no precise publication. The maintained catalogue classifies #966 **PROVED (LEAN)** after a February 2026 AI-assisted proof and formalization. The argument below supplies a complete elementary reduction to the classical **Hales–Jewett theorem**; GCL has *not* kernel-replayed the publicly linked Lean files. [Erdős Problem #966](https://www.erdosproblems.com/966).

The word *nonconstant* is essential. Counting a progression with common difference zero would trivialize both conditions, and the prohibited \((k+1)\)-term progression must have distinct terms.

## An elementary warm-up

For \(k=r=2\) the set \(A=\{1,2,4\}\) works. It has no three-term arithmetic progression: \(1,2,4\) have unequal adjacent gaps \(1,2\). In every two-coloring of its three points, some two points have the same color by the pigeonhole principle; any two distinct integers form a nonconstant two-term arithmetic progression. This proves just the smallest case, not the general theorem.

## A construction for all \(k,r\)

**External theorem (Hales–Jewett).** For every alphabet size \(k\) and color count \(r\), there is a positive integer \(N\) such that every \(r\)-coloring of the word cube
\[
D^N,\qquad D=\{0,1,\ldots,k-1\},
\]
contains a monochromatic *combinatorial line*: \(k\) words \((w^{(a)})_{a\in D}\) for which there is a nonempty set of wildcard coordinates \(W\subseteq\{0,\ldots,N-1\}\); at each coordinate in \(W\) the word \(w^{(a)}\) has digit \(a\), while at each coordinate outside \(W\) every word uses one fixed digit, independent of \(a\).

Take \(q=2k+1\) and form the **finite** set
\[
A=\left\{\,1+\sum_{i=0}^{N-1}d_iq^i:
             d_i\in\{0,1,\ldots,k-1\}\,\right\}.
\]
Every element is a positive integer. Base-\(q\) uniqueness makes the map from digit words injective, so \(|A|=k^N\).

**First, \(A\) contains no nonconstant \((k+1)\)-term arithmetic progression.** Suppose instead
\[
x_0,x_1,\ldots,x_k\in A,\qquad
x_j=x_0+jD,\quad D\ne0.
\]
Write \(x_j=1+\sum_i d_{j,i}q^i\) with \(0\le d_{j,i}\le k-1\). For each \(j=0,\ldots,k-2\),
\[
x_j+x_{j+2}-2x_{j+1}=0.
\]
Reducing this equation modulo \(q\), its least-digit expression
\[
d_{j,0}+d_{j+2,0}-2d_{j+1,0}
\]
is a multiple of \(q\). Its absolute value is at most \(2(k-1)<q\), so it must equal zero. Subtract these now-vanishing least-digit contributions and divide the equation by \(q\); repeat inductively through all \(N\) coordinates. Thus, for *each* fixed digit position \(i\), the sequence
\[
d_{0,i},d_{1,i},\ldots,d_{k,i}
\]
is an integer arithmetic progression of \(k+1\) elements inside an alphabet of only \(k\) consecutive integers. It cannot have nonzero common difference; therefore it is constant. All coordinates of all \(x_j\) agree, whence \(D=0\), a contradiction.

**Second, every \(r\)-coloring of \(A\) has a monochromatic \(k\)-term arithmetic progression.** Pull the coloring back through the injective base-\(q\) map to an \(r\)-coloring of \(D^N\). Hales–Jewett supplies a monochromatic combinatorial line with nonempty wildcard set \(W\). The corresponding positive integers are
\[
x_a=C+aQ,\qquad a=0,1,\ldots,k-1,
\quad
Q=\sum_{i\in W}q^i>0,
\]
where \(C\) incorporates the leading 1 and the fixed digits outside \(W\). Hence they form a nonconstant **monochromatic** arithmetic progression of length \(k\). Both properties hold simultaneously for this one finite set \(A\), proving the conjecture for all \(k,r\ge2\).

This reduction is rigorous provided the cited **Hales–Jewett theorem** is taken as an established external theorem. It does not use the much stronger density Hales–Jewett theorem, nor a statement about an infinite set.

## Why the construction is instructive

The two constraints pull in opposite directions. A Ramsey-rich set must contain enough arithmetic progressions of length \(k\) for arbitrary colorings to force a monochromatic one; a progression-free set must prohibit all progressions of length \(k+1\). The digit alphabet \(\{0,\ldots,k-1\}\) enforces the latter condition **coordinatewise**, while the Hales–Jewett wildcard line guarantees the former. Choosing a base strictly larger than twice the largest possible digit is the no-carry mechanism that prevents a false coordinatewise argument.

The set's size \(k^N\) is typically enormous, since quantitative Hales–Jewett bounds are large. Existence, rather than a good bound on the smallest \(|A|\), is the question here. Optimizing its size would be a separate extremal problem.

## Provenance and formalization boundary

The original problem comes from P. Erdős, *Problems and results in combinatorial number theory* [Er75b], *Journées Arithmétiques* (1975), pp.295–310. Erdős credited an earlier announcement to Spencer but did not supply a proof location. A 25 February 2026 comment by JoshuaB reported that the AI system Aristotle, given the statement, produced a Lean formalization involving Hales–Jewett; the public source page now marks the answer **PROVED (LEAN)**. The Formal Conjectures source file gives the quantifiers
\[
\forall k,r\ge2\ \exists A\subseteq\mathbb N,\quad
\text{AP}_{k+1}\text{-free}(A)\ \land\
\forall c:A\to\{0,\ldots,r-1\},\
\text{\(c\) has a monochromatic AP}_k.
\]
An upstream statement file linking to a purported separate proof while still containing a proof placeholder is **not by itself** a complete kernel verification of that theorem. The linked proof file, the dependency containing Hales–Jewett, the exact compiler version and the resulting axiom report must be independently checked before giving it a GCL formal-certification receipt.

The independent base-\(q\) construction above establishes the **mathematical result relative to an accepted standard combinatorial theorem**. It does not claim that GCL discovered the proof, that the earliest Spencer argument was this same construction, or that GCL independently compiled the external formal proof.
