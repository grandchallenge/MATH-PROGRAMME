## The question in plain language

An integer is **squarefree** if it has no repeated prime factor: no prime square divides it. For example, $6$ is squarefree but $12$ is not.

[Erdős Problem #1102](https://www.erdosproblems.com/1102) asks how large a sequence $A$ can be while certain shifted integers $n+a$ are, or are not, squarefree.

The original problem contains several **different quantified properties**. Understanding which shift is held fixed matters.

## A small example

Property $P$ says that for every *fixed* $n\ge1$, only finitely many $a\in A$ have $n+a$ squarefree.

Property $Q$ says that for **infinitely many** positive integers $n$, all $a\in A$ satisfying $a<n$ have $n+a$ squarefree.

A finite set such as $A=\{1,4\}$ automatically has $P$, because it contains only two elements. Searching $n\le100$ finds numerous values, including $n=6$, for which both $n+1$ and $n+4$ are squarefree. That finite computation is **not** evidence that $Q$ holds for infinitely many $n$.

Separately, exactly 61 integers between $1$ and $100$ are squarefree, consistent with the known asymptotic proportion $6/\pi^2$, but one finite proportion does not prove the density theorem.

## What is known

Many of Erdős's questions were resolved by **van Doorn and Tao (2025)**, according to the maintained catalogue. It reports the following external results:

- Every set with $P$ has natural density zero, but this density may approach zero arbitrarily slowly.
- Any set with $Q$ has upper density at most $6/\pi^2$, and this bound is attainable.
- The related properties $P'$ and $P'_\infty$, which demand squarefree shifts for *all* or *all but finitely many* elements along infinitely many $n$, have further sharp density restrictions.

Two explicit families, $2^j\pm1$ and $j!\pm1$, were shown to satisfy $Q$. The catalogue still identifies their satisfaction of $P$ as **open**.

Thus the parent problem may be catalogued as solved while named subquestions remain open.
