## The question in plain language

A planar subset is in convex position when every selected point is a vertex of its convex hull. Erdős and Hammer asked how many such subsets every input point set must contain, and whether the logarithmic growth has a sharp leading constant.

For n points in R² with no three collinear, count subsets that are in CONVEX POSITION: each chosen point is a vertex of the convex hull of the subset. f(n) is the minimum over all input configurations of the number of such subsets. Does log f(n)/(log n)² converge to a universal constant? Subsets of a finite point set cannot be geometrically convex sets in the literal set-theoretic sense except singletons, so use convex-position terminology.

## A small example

Four vertices of a strictly convex quadrilateral give all 2^4=16 subsets in convex position if empty set is counted (15 nonempty). Three triangle vertices and one interior point give exactly 15 subsets including empty: only the full four-element set is not in convex position, assuming no three collinear. Convexity of singleton/pairs is by convention.

This finite calculation is not an asymptotic or all-parameter proof.

## What is known

Maintained /latex/838 read 2026-10-14: Erdős–Hammer question, Erdős [Er78c] (1978) proved n^(c1 log n)<f(n)<n^(c2 log n) for some positive constants. These bounds imply log f(n) is of order (log n)², but do not prove the ratio tends to a fixed limit. #107 related. Original 1978 proof not independently replayed.

The source-reported bounds have the form

$$

\exp(c_1(\log n)^2)<f(n)<\exp(c_2(\log n)^2)

$$

for some positive constants. This does not prove that $\log f(n)/(\log n)^2$ converges. A subset counts as in convex position when each selected point is an extreme point of its own convex hull. The empty-set convention affects the count only by one.
