## The question in plain language

[Erdős Problem #1175](https://www.erdosproblems.com/1175) is classified **OPEN** in the maintained catalogue.

For **each** uncountable cardinal $\kappa$, does there exist **some** cardinal $\lambda$ (possibly larger than $\kappa$) so that **every** graph $G$ of chromatic number $\chi(G)=\lambda$ contains a **triangle-free subgraph** $H$ with $\chi(H)=\kappa$? The quantifier order is $\forall\kappa\ \exists\lambda\ \forall G\ \exists H$. Subgraph need not be induced unless the original theorem says so; equality versus $\ge\kappa$ for the subgraph chromatic number must be verified. A counterexample at $\lambda=\kappa$ is **not enough** to refute possible larger $\lambda$.

## A small example

$K_5$ has chromatic number five and contains $C_5$ as a spanning, noninduced, **triangle-free** subgraph with chromatic number three. Exhaustive proper-coloring enumeration checks that the five-cycle cannot be colored with two vertex colors but admits a three-coloring. This shows a concrete high-chromatic graph with a smaller triangle-free chromatic subgraph, but does **not** give a universal $\lambda$ for any uncountable cardinal.

## What is known

The maintained catalogue [Va99,7.92] leaves the general assertion **OPEN**. Shelah reportedly showed that it is consistent for the special $\kappa=\lambda=\aleph_1$ instance to fail: some graph of chromatic number $\aleph_1$ lacks a triangle-free subgraph of chromatic number $\aleph_1$. But the original statement permits a **different $\lambda$** for the same $\kappa$, so that relative-consistency obstruction does **not disprove** the $\forall\kappa\exists\lambda$ conjecture. The site marks it formalized; formalization without a kernel proof is not mathematical certification.
