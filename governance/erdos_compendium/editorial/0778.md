## The question in plain language

Erdős described three games in which two players claim the edges of a complete graph. In the main game, Alice and Bob alternately colour edges red and blue. Alice goes first and wins only when her final red graph has a strictly larger clique than Bob's blue graph; **a tie is a Bob win**.

Erdős asked whether Bob always wins for $n\geq3$. He also asked a biased game where Bob takes two edges per Alice edge but must achieve a *strictly larger* clique, and a game comparing maximum vertex degrees instead of clique sizes. These are three different questions. None is fully settled at its original parameters.

## A small example

On $K_3$ there are three edges. With one edge claimed per turn, Alice gets two and Bob gets one. Each graph contains an edge but neither contains a triangle, so each has clique number two. Therefore Bob wins through the tie rule, regardless of the order in which available edges were selected.

This is a valid result for $n=3$ only. In the biased game, the winning tie condition differs, so the same reasoning cannot simply be reused to decide it.

## What is known

Alexandru Malekshahian and Sam Spiro, [*On a clique-building game of Erdős*](https://arxiv.org/abs/2410.18304), arXiv:2410.18304v2 (5 May 2026), define the games and prove several partial results. Their Theorem 1 shows that Bob wins the ordinary clique game for a set of $n$ having asymptotic density at least $3/4$. More concretely, if Alice can win at $n$, then Bob can win at $n+1,n+2,n+3$. This conclusion is **not** victory for every $n$.

Their Theorem 2 treats the maximum-degree (*star*) game: Bob wins for a set of $n$ of density at least $2/3$, using ana\logous three-consecutive-parameter reasoning. Theorem 3 of version 2 concerns the biased game. In particular, for sufficiently large $n$ Bob can win when Alice claims one edge per turn and Bob claims **four**, rather than the two edges proposed by Erdős.

A central subtlety is the tie convention. In the unbiased clique game, Alice must strictly beat Bob; in the biased game where Bob claims more edges, Bob must strictly beat Alice. Reversing the convention would reverse several small-case outcomes and invalidate a strategy-stealing argument.

The paper uses a strategy-stealing and dimension-extension mechanism: hypothetical Alice victories at a smaller order force Bob victories at nearby larger orders. This yields density statements, not a uniform proof.

## GCL's current state

The [authenticated #778 source audit](https://github.com/grandchallenge/MATH-PROGRAMME/issues/2049#issuecomment-6168007527) checked the 2026 version 2 of the authors' primary paper and all three recorded game definitions. The catalogue [#778](https://www.erdosproblems.com/778) remains OPEN; the published fractional-density results are evidence of progress, not resolution. No full strategy proof has been independently re\produced by GCL.

## What remains

Implement a bounded finite minimax solver for $K_3$ and $K_4$ that assigns each edge to the actual player on their scheduled turn, evaluates clique and degree scores only after the game ends, and uses the correct tie priority for each variant. Keep the biased $(1,2)$ and $(1,4)$ cases separate. Review the original Guy 1983 statement before treating any later game variant as identical.
