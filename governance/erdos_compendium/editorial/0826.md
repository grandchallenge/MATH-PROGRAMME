## The question in plain language

Are there infinitely many n for which a single absolute implied constant K satisfies tau(n+k)<=K k simultaneously for ALL integers k>=1? Quantifiers: there exist infinitely many n each satisfying every k with uniform constants; not merely for each fixed k separately.

## A small example

For n=1, k=1..5 gives n+k=2..6 with tau values 2,2,3,2,4. The ratios tau(n+k)/k decrease in this finite sample but cannot certify the requirement for all k or infinitely many n.

The example can be checked exactly. A finite witness does not replace the universal, asymptotic, or infinitely-often quantifiers in the original question.

## What is known

Maintained https://www.erdosproblems.com/latex/826 read 2026-10-14 OPEN; C. F. Lau [La26], arXiv:2604.15042 (2026), proves infinitely many n with tau(n+k)<<k^C for all k>=1 for some fixed C. Polynomial in k is not a linear bound. Related to #248. Original preprint full proof and C value not independently read.

The demanded uniform bound is

$$

\tau(n+k)\leq Ck\qquad\text{for every }k\geq1,

$$

on infinitely many selected $n$ with the same absolute constant $C$. Lau's 2026 partial theorem gives $O(k^B)$ for an absolute exponent $B$ instead. Even when a fixed $B$ exists, $k^B$ is not $O(k)$ unless $B\leq1$, which is not established by that theorem.
