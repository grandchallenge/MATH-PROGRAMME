## The question in plain language

What block-size sequences are possible in a pairwise-balanced design? Given n points, choose blocks so that every unordered pair is contained in exactly one block. The question [Erdős #732](https://www.erdosproblems.com/732) asks for a classification and, separately, for at least $\exp(c\sqrt{n}\log n)$ distinct compatible sorted size sequences.

## A small example

For n=4, all six unordered vertex pairs form a design with six size-2 blocks, hence the sequence (2,2,2,2,2,2) is compatible. For n=7, the seven Fano triples {j,j+1,j+3} modulo 7 each meet every unordered point pair exactly once, so the sequence (3,3,3,3,3,3,3) is compatible.

## What is known

Counting pairs inside blocks forces $\sum_i\binom{X_i}{2}=\binom{n}{2}$, an elementary necessary condition. The maintained source credits Erdős with an upper $\exp(O(\sqrt{n}\log n))$ for the number of sorted compatible sequences and Noga Alon with the matching exponential-scale lower bound $2^{(1/2+o(1))\sqrt{n}\log n}$. Thus the counting lower-bound question is PROVED. This does not amount to a general constructive necessary-and-sufficient criterion for an arbitrary proposed sequence.
