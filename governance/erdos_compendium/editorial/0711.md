## The question in plain language

[Erdős #711](https://www.erdosproblems.com/711) concerns f(n,m), the least F such that the OPEN interval (m,m+F) contains n distinct integers a_1,...,a_n, each a_k divisible by k. The first question asks max_m f(n,m)≤n^(1+o(1)). The second asks whether max_m(f(n,m)−f(n,n)) grows without bound. The maintained problem is still **OPEN** because the first question remains unresolved; the second has an attributed proof.

## A small example

For n=1, the open interval (m,m+2) contains m+1 and is minimally long, so f(1,m)=2. For n=2, (m,m+3) contains exactly m+1 and m+2; one is even and the other can be used for a_1, so f(2,m)=3. Thus the first two small values have no offset-sensitive excess at all. The source's divergence is an n→∞ statement.

## What is known

The source credits Erdős–Pomerance [ErPo80] with max_m f(n,m)≪n^(3/2), and two-sided bounds for the special starting point f(n,n). It reports that Wouter van Doorn [vD26] proved the SECOND question positively, showing for all sufficiently large n there exists an offset m with f(n,m)−f(n,n)≫n log n/loglog n. That quantitative result does not imply max_m f(n,m)≤n^(1+o(1)), and the original source remains open in that respect. Original [ErPo80] and [vD26] theorem pages are not independently inspected in this audit.
