## The question in plain language

[Erdős Problem #1191](https://www.erdosproblems.com/1191) is **OPEN** in the maintained catalogue.

An infinite **Sidon set** $A\subset\mathbb N$ has unique sums of two elements up to order, **including repeated summands**. Erdős asks whether every such set satisfies

$$
\liminf_{x\to\infty}\frac{|A\cap[1,x]|}{\sqrt x}\sqrt{\log x}=0,
$$

and separately whether **some** infinite Sidon set has $\liminf_{x\to\infty}|A\cap[1,x]|(\log x)^c/\sqrt x>0$ for any fixed $c>0$. These are **not logical negations** for arbitrary $c$: for $0<c<1/2$, both can hold. The $\liminf$ differs materially from $\limsup$ (see #729).

## A small example

The ten powers of two $1,2,4,\ldots,512$ form a finite Sidon set: exhaustive enumeration of all 55 unordered sums with repetition finds no collisions. The infinite powers-of-two set has counting function $\lfloor\log_2x\rfloor+1$, far below $\sqrt{x/\log x}$, and therefore is **not** an example of the potentially dense Sidon set sought in the second question. Its sparse growth is an elementary example, not a universal upper bound for all Sidon sets.

## What is known

The maintained https://www.erdosproblems.com/1191 labels both questions **OPEN**, original [Er80,p.98]. Erdős proved a bounded $\liminf$ at exponent $1/2$ up to some constant [HaRo66], which does **not** yield zero. The second problem strengthens #39; the limsup belongs to #729. The page notes a historical \$1000 prize for clarifying these problems, which should not be treated as evidence of an unclaimed active award or a proof.
