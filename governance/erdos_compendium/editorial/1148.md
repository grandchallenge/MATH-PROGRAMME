## The question in plain language

[Erdős Problem #1148](https://www.erdosproblems.com/1148) concerns the following mathematical question and its exact quantifiers:

$$
n=x^2+y^2-z^2,\qquad \max(x^2,y^2,z^2)\le n.
$$

For every sufficiently large positive integer n, find INTEGER x,y,z satisfying n=x²+y²-z² with max(x²,y²,z²)<=n. Signs do not change the squares; x,y,z may be chosen nonnegative. This is an EVENTUAL representation theorem, not assertion that every n is representable. Important that component squares separately stay <=n, not merely absolute value bound of x²+y²-z².

## A small example

An independent exact perfect-square set search verifies for every n<=300 which representations exist and that 6563 has NO representation with all x²,y²,z²<=6563; 6564 DOES have one. This is a bounded witness and not proof of a finite exceptional set or the full ELMV12 mechanism. Fixture uses identity n+z²=x²+y² with each square<=n.
