## The question in plain language

Let $\mathbb N$ mean the positive integers. Given a function $f:\mathbb N\to\mathbb N$, form

$$
S(f)=\sum_{n=1}^{\infty}\frac{1}{\prod_{i=1}^{f(n)}(n+i)}.
$$

Erdős and Graham asked whether the condition

$$
\lim_{n\to\infty}f(n)=\infty
$$

forces $S(f)$ to be irrational. Read as a proposition, the question asks whether, for every positive-integer-valued $f$ whose values eventually exceed every fixed bound, one has $S(f)\notin\mathbb Q$. There is no monotonicity hypothesis in this original quantifier. The condition $f(n)\to\infty$ permits the values to go up and down, provided that after some point they stay above each prescribed threshold.

The last point matters because the source also mentions a different question: what if $f$ is nondecreasing? That is a stronger restriction and a different problem. A result for the unrestricted class does not automatically produce a result for the nondecreasing subclass. The original wording appears on printed page 66 of Erdős and Graham’s 1980 problem book; the scanned page is source-pinned below.

## A small example

The series’ indexing is easy to shift accidentally, so here is an exact finite check of the denominator pattern. For integers $N\geq 1$ and $m\geq 1$, telescoping gives

$$
\sum_{n=m}^{\infty}\frac{1}{\prod_{i=1}^{N+1}(n+i)}
=\frac{1}{N\prod_{i=1}^{N}(m+i)}.
$$

Indeed,

$$
\frac{1}{(n+1)(n+2)(n+3)}
=\frac12\left(\frac{1}{(n+1)(n+2)}-\frac{1}{(n+2)(n+3)}\right).
$$

Taking $N=2$ and $m=3$ therefore gives an exact value of $1/40$. If the sum stops at $L=10000$, the omitted tail is exactly

$$
\frac{1}{40}-\sum_{n=3}^{10000}\frac{1}{(n+1)(n+2)(n+3)}
=\frac{1}{2\cdot10002\cdot10003}
=\frac{1}{200100012}.
$$

This can be reproduced without floating point:

```python
from fractions import Fraction

partial = sum(
    (Fraction(1, (n + 1) * (n + 2) * (n + 3)) for n in range(3, 10001)),
    Fraction(0),
)
assert Fraction(1, 40) - partial == Fraction(1, 200100012)
```

The same calculation is recorded in the authenticated source-audit return [RESULT/1](https://github.com/grandchallenge/MATH-PROGRAMME/issues/1540#issuecomment-6138000286). It checks a finite identity only; it is not itself a counterexample, because the displayed finite choice does not define a function on all $n$ with $f(n)\to\infty$.

## What is known

The answer to the original unrestricted question is disproved, and in a particularly strong way. Crmarić and Kovač prove in Theorem 1 of their paper, printed arXiv PDF page 2, that

$$
\left\{S(f):f:\mathbb N\to\mathbb N,\ f(n)\to\infty\right\}=(0,\infty).
$$

Thus for every prescribed $\alpha>0$ there exists an admissible $f$ with $S(f)=\alpha$. Choosing the rational value $\alpha=1$ supplies an $f$ for which the sum is rational, so the universal irrationality claim is false. This is an existence conclusion: the theorem does not say that every such $f$ has rational sum, nor does it give a simple closed formula for the witness $f$ at $\alpha=1$.

Their proof partitions the positive integers into the dyadic layers

$$
S_j=2^{j-1}(2\mathbb N-1),\qquad j\geq1,
$$

and builds finite families of local choices on each layer. The generalized subsum principle is Lemma 4, printed PDF pages 4–6; the construction applying it is in Section 3, pages 6–9. The choices are arranged so that the layer sums fill intervals and the assembled function still satisfies $f(n)\to\infty$. No monotonicity is imposed.

The same paper’s Theorem 2, printed PDF page 3, concerns the nondecreasing subclass. It says that the set of sums arising from increasing $f$ has Lebesgue measure zero and empty interior. That statement does not identify whether this smaller set contains a rational number. Accordingly, the increasing version remains open on the evidence inspected here. The maintained Erdős Problems entry reports exactly this distinction: the unrestricted question has a strong negative answer, while the nondecreasing question may still have an affirmative irrationality answer.

## What remains

For the original problem, the mathematical status is **disproved**: Theorem 1 supplies a rational value in the unrestricted value set. The remaining mathematical question is the semantically distinct nondecreasing variant. Theorem 2 narrows its possible values topologically and measure-theoretically, but “measure zero” does not mean “contains no rational,” so no upgrade to proved or disproved is justified there.

The formal task is narrower and still open as a documentary matter. A future replay would need to bind the exact external source, toolchain, theorem type, imports, and axioms, and compare its function and index conventions with the original expression. In particular, it must retain positivity of $f(n)$ and the limit-to-infinity hypothesis. A successful project build or a theorem whose body contains `sorry` would not establish the mathematical result. The source audit therefore remains `PARTIAL`, and this manuscript preserves that exception rather than upgrading formal metadata into proof authority.
