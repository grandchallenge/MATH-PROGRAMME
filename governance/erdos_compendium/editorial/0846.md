## The question in plain language

The local condition that every finite sample of a planar set has a large no-three-collinear subset need not make the entire infinite set a finite union of such configurations. This is an infinite compactness-style obstruction, not a failure visible in four sample points.

Let A be an INFINITE planar point set such that some fixed epsilon>0 guarantees every finite n-point subset B of A contains at least epsilon n points with no three collinear. Does A decompose into finitely many no-three-collinear classes? NO. The local fractional independence property is not the same as finite chromatic number of the 3-collinearity hypergraph.

## A small example

Finite four-point set {(0,0),(0,1),(1,0),(1,3)} has no three collinear; it is trivially one-colorable as a finite geometry instance. Any fixed finite example necessarily has finite partition number, so it cannot witness the infinite counterexample. The finite predicate is nevertheless testable by determinant.

A finite instance tests the definition, not a claim quantified over every large graph, infinite set or arbitrary coloring.

For a finite B in the infinite set A, let alpha(B) be the maximum size of a subset with no collinear triple. The condition is alpha(B)>=epsilon|B| for every finite B with one epsilon. A finite cover by no-three-collinear classes means the collinearity 3-uniform hypergraph of A is finitely colorable. The cited constructions separate positive local fractional independence from finite global chromatic number. Finite configurations alone cannot show such an infinite failure.
