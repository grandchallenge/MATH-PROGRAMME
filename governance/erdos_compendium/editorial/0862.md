## The question in plain language

A Sidon set contains positive integers with distinct unordered pair sums, including doubles. A Sidon set is *inclusion-maximal* in $\{1,\ldots,N\}$ if no further number from that interval can be added without breaking the Sidon property. This is **not** the same as having the largest possible number of elements.

Write $A_1(N)$ for the number of all inclusion-maximal Sidon subsets of $\{1,\ldots,N\}$. Erdős and Cameron asked in [Problem #862](https://www.erdosproblems.com/862) whether

$$
A_1(N)<2^{o(\sqrt N)}
$$

and whether $A_1(N)>2^{N^c}$ for some constant $c>0$.

The two proposed behaviors differ dramatically. The first suggests there are surprisingly few maximal sets. The second asks whether their number nevertheless grows exponentially in a power of $N$.

## A small example

Any finite Sidon set can be enlarged one admissible element at a time until it becomes inclusion-maximal. The process must stop because the ground set is finite. Different starting sets can lead to the same maximal set, so counting extensions is not simply counting original sets.

For the exact finite problems, two independent enumeration methods give:

| $N$ | All Sidon sets $A(N)$ | Maximal Sidon sets $A_1(N)$ | Largest size $f(N)$ |
|---:|---:|---:|---:|
| 10 | 216 | 64 | 4 |
| 18 | 3694 | 1086 | 6 |

The reproducible program governance/erdos_compendium/research/EC-BULK-006/finite_862.py computes inclusion-maximality by testing every omitted element; an independent combinations-based procedure cross-checks it through $N=12$. These computations are finite examples, not asymptotic proof.

## What is known

Let $A(N)$ count **all** Sidon subsets and $f(N)$ the maximum size of one, as in [Problem #861](https://www.erdosproblems.com/861). Every Sidon subset is contained in some maximal Sidon set. A fixed maximal set of size $k\le f(N)$ has only $2^k\le2^{f(N)}$ subsets, so

$$
A(N)\le A_1(N)2^{f(N)},
\qquad
A_1(N)\ge\frac{A(N)}{2^{f(N)}}.
$$

This *covering inequality* is elementary, but it is the exact bridge from the solved counting problem #861 to #862.

Saxton and Thomason prove in [Theorem 1.10 and Section 5](https://arxiv.org/html/1611.01433) that $A(N)\ge2^{(\log_2\sqrt5+o(1))\sqrt N}$. Combining it with the classical bound $f(N)=(1+o(1))\sqrt N$ gives

$$
A_1(N)\ge
2^{(\log_2\sqrt{5/4}+o(1))\sqrt N},
\qquad
\log_2\sqrt{5/4}\approx0.160964>0.
$$

Therefore the proposed $2^{o(\sqrt N)}$ upper growth is **false**, and the existence of some $c>0$ with $A_1(N)>2^{N^c}$ is **true**. The original two questions appear on [Erdős (1992), printed p.39](https://hrj.episciences.org/125/pdf). The maintained catalogue lists #862 as solved, with an externally reported Lean formalization.

## GCL's current state

The source audit recorded on [original assignment #2133](https://github.com/grandchallenge/MATH-PROGRAMME/issues/2133) separates three levels of evidence. First, the finite maximal-extension and counting inequalities have elementary proofs. Second, their asymptotic consequences depend on the independently published Saxton–Thomason construction and the classical asymptotic for $f(N)$. Third, the existence of external Lean source does not mean GCL has recompiled its exact dependencies.

The maintained discussion refers to a Lean formalization initially depending on a prime-neighbor statement called *prime_between*. A later source-level check of an external file in plby/lean-proofs, path src/v4.29.1/ErdosProblems/Erdos862.lean, found an import from PrimeNumberTheoremAnd.Consequences and a theorem using the imported prime-between result. That is better provenance than an unexplained bare axiom, but it is not yet an independently replayed build or an independently inspected actual axiom report.

GCL has now saved exact finite_862.py and finite_862.json fixtures. They test that every enumerated Sidon set admits a maximal extension and that $A(N)\le A_1(N)2^{f(N)}$ for the enumerated cases. At $N=18$, the verified values are $A(18)=3694$, $A_1(18)=1086$, and $f(18)=6$.

## What remains

The original problem is mathematically settled as a consequence of #861. The appropriate bounded formal task is not to launch another proof search for the asymptotic conclusion. It is to formalize the *finite covering lemma* and identify the exact asymptotic inputs.

The input is a finite ground set with a Sidon predicate on unordered pairs including repetitions. The target is a statement that every Sidon set extends to a maximal one and the cardinality inequality $A(N)\le A_1(N)2^{f(N)}$. Acceptance is a type-checked Lean proof with no placeholders, verified against the exact finite fixtures at $N=10,18$. A Sidon subset that cannot be extended, or a violated finite inequality, would falsify the formulation.

A separate provenance gate must pin the external Lean toolchain, dependency commit, imported prime theorem, and literal output of its axiom audit. Stop at these bounded tasks rather than claiming an independent Lean certification of the complete asymptotic result.
