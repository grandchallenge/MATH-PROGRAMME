## The question in plain language

Define the size Ramsey number Rhat(G) as the smallest number of edges of a host graph H such that every red–blue edge-colouring of H has a monochromatic copy of G. Erdős–Faudree–Rousseau–Schelp asked three different asymptotic questions: (i) does Rhat(P_n)/n→∞ for a path of length n? (ii) does Rhat(P_n)/n²→0? (iii) does Rhat(C_n)=o(n²)? Beck 1983 proved Rhat(P_n)=O(n) AND Rhat(C_n)=O(n). Thus (i) is DISPROVED, (ii) and (iii) PROVED. The maintained page's single aggregate badge 'PROVED' must not be read as an affirmative resolution of all three.

## A small example

Any host arrowing a path P_n must contain at least one copy of P_n, hence at least n edges (the path is specified to have length n). Thus Rhat(P_n)≥n. Beck's linear upper bound gives Rhat(P_n)=Θ(n), so Rhat(P_n)/n stays bounded above AND bounded away from zero; it does not diverge, while the ratio divided by n² tends to zero. Similarly a cycle with n edges requires Rhat(C_n)≥n and the upper bound gives Θ(n).

## What is known

The maintained #720 attributes the original questions to Erdős, Faudree, Rousseau and Schelp [EFRS78b], and a decisive linear bound to József Beck [Be83b], 'On size Ramsey number of paths, trees, and circuits', Journal of Graph Theory 7 (1983), 115–129. Bibliographic title/journal attribution is primary-publisher metadata but the full original proof and constants were not independently reconstructed. Be careful about P_n denoting n vertices versus n edges: the catalogue explicitly uses path LENGTH n, whereas many original papers index vertices; either convention yields equivalent Θ(n) asymptotics but different finite values. Source page reports PROVED because its overall questions were resolved, though one answer was negative.
