## The question in plain language

The three-term-arithmetic-progression analogue of the infinite planar coloring problem is also negative. Every finite subset of the constructed infinite set has a large progression-free part, yet no finite coloring of the whole set avoids monochromatic progressions.

Let A be an INFINITE subset of positive integers. Assume some fixed epsilon>0 such that every finite B subset A contains a 3-term-AP-free subset of cardinality at least epsilon|B|. Does A admit a partition into finitely many 3AP-free parts? NO. The local finite independent-ratio property does not guarantee finite global hypergraph chromatic number.

## A small example

Take B={1,2,3,4}. Its maximum 3AP-free subset has cardinality three: e.g. {1,2,4} works; full set contains 1,2,3 and 2,3,4 arithmetic progressions. This finite calculation illustrates an independent ratio 3/4 but does not address any infinite coloring obstruction.

This finite calculation tests definitions, not a result quantified over all large N or infinite sets.

## What is known

This disproves the partition conjecture. Proof not independently replayed.

For a finite B the maximum cardinality of a three-term-progression-free subset is a hypergraph independence number. Positive uniform lower fraction in each finite B does not bound the chromatic number of the entire infinite hypergraph. Reiher, Rödl and Sales construct an infinite set with this exact separation for any specified proportion below one half. B={1,2,3,4} illustrates the local definition: it has maximum AP-free subset size three, for example {1,2,4}, whereas B itself contains both 1,2,3 and 2,3,4 progressions.
