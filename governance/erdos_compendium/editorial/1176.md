## The question in plain language

[Erdős Problem #1176](https://www.erdosproblems.com/1176) asks the following. The maintained status is **NOT DISPROVABLE**.

Let $G$ have **vertex** chromatic number $\aleph_1$. Can one assign $\aleph_1$ colors to its **edges** so that, under every subsequent **countable vertex coloring**, some vertex-color class contains edges in every edge color? The two colorings have different domains and palettes. The statement requires the distinguished class to see every edge color, not merely one color or every vertex color class to work.

## A small example

On the one-edge graph $K_2$, proper two-coloring of the vertices gives two independent singleton classes. Neither contains any edge, so neither contains the edge's assigned color. This checks a simple **finite chromatic-two** obstruction but says nothing about a graph of chromatic number $\aleph_1$.
