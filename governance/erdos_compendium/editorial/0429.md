## The question in plain language

Suppose we choose an infinite set $A$ of positive integers so sparse that its elements are far apart. Could there be one integer shift $n$ that makes **every** number $n+a$, with $a\in A$, prime? Erdős Problem 429 asks whether this should be possible whenever the set is sufficiently sparse and there is no obvious modular obstruction.

The modular condition is called *admissibility*. For every prime $p$, the set $A$ must miss at least one residue class modulo $p$. If $A$ occupied **all** residue classes modulo some prime $p$, then every shift $n$ would place at least one member of $n+A$ in residue class zero modulo $p$. For a large enough element, that number would be composite. Thus missing a residue class for every prime is an obvious necessary condition for translating an infinite set wholly into the primes.

The subtle point is whether this necessary condition is sufficient when the set is very sparse. The question is different from the prime $k$-tuple conjecture, which concerns **finite** admissible patterns. A result about each finite prefix separately does not provide a single shift that works for every element of an infinite set.

## A small example

Consider the finite set $A=\{2,4\}$. It is admissible. Modulo $2$, both elements are congruent to zero, so residue class $1$ is missing. For any odd prime $p$, the two members occupy at most two residue classes, fewer than the $p\geq3$ available classes, so at least one class is missing. Moreover, the shift $n=1$ makes

$$
n+A=\{3,5\},
$$

and both numbers are prime.

This example shows that the modular condition is compatible with a finite prime translate; it does not prove the desired property for every admissible set. It also does not say anything about the existence of a **single** prime translate for an infinite set. Even if every finite prefix had some suitable shift, those shifts could vary with the size of the prefix and need not agree.

The modular necessity argument is fully rigorous for infinite sets: if an infinite $A$ covers all residue classes modulo $p$, then for every shift $n$ there is an entire infinite subsequence to consider only if an infinite congruence class is populated; the simple finite covering argument alone needs care because a single number divisible by $p$ might equal $p$ itself. For sufficiently large fixed finite subsets that repeat the residue obstructions, one can force composites; the historical admissibility condition is the standard necessary local test for prime-rich patterns. The negative solution constructs a much stronger obstruction that survives despite this local admissibility.

## What is known

The question appears in P. Erdős, *A survey of problems in combinatorial number theory*, *Annals of Discrete Mathematics* (1980), printed p. 111, and in Erdős and Graham, *Old and New Problems and Results in Combinatorial Number Theory* (1980), printed p. 85 of the [scanned book](https://mathweb.ucsd.edu/~ronspubs/80_11_number_theory.pdf).

Desmond Weisenberg settled the conjecture negatively in [*Sparse Admissible Sets and a Problem of Erdős and Graham*](https://arxiv.org/abs/2405.12310), published in *INTEGERS* 24 (2024), Article A89. His paper shows that there are **arbitrarily sparse infinite admissible sets** $A$ for which there exists **no integer** $n$ making every element of $n+A$ prime. The constructions are explicit in a mathematical sense and use properties of powers of primitive roots; the paper provides four approaches. The result demonstrates that even severe sparseness together with the absence of local residue-class obstructions is not sufficient.

The maintained [Erdős Problems #429](https://www.erdosproblems.com/429) page, last edited on April 8, 2026, labels the answer **DISPROVED (LEAN)** and attributes the negative result to Weisenberg. A related question replaces primes with squarefree integers and asks whether a set omitting some residue class modulo every $p^2$ admits infinitely many shifts whose translates are all squarefree. The maintained source also reports a negative answer through a variant of Weisenberg's construction. The squarefree variant has different local conditions and cannot be silently merged into the original prime question.

The negative result does not contradict the prime $k$-tuple conjecture. That conjecture concerns any specified finite admissible set; each finite subset of the constructed infinite $A$ can be treated as a different finite pattern. It does not promise that one shift succeeds for all infinitely many members simultaneously.
