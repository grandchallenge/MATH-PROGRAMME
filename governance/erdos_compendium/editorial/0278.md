## The question in plain language

Choose distinct positive integers

$$
n_1<n_2<\cdots<n_r
$$

and, for each modulus $n_i$, choose one residue class $a_i+n_i\mathbb Z$. The question asks how much of the integer line these classes can cover. Write

$$
U(a_1,\ldots,a_r)=\bigcup_{i=1}^r(a_i+n_i\mathbb Z),
\qquad
\mu(a_1,\ldots,a_r)=\mathrm{dens}(\mathbb Z\setminus U(a_1,\ldots,a_r)).
$$

If $L=\mathrm{lcm}(n_1,\ldots,n_r)$, then $U$ repeats every $L$ integers. Its density is therefore the exact fraction of residues covered in one period:

$$
\mathrm{dens}(U)=\frac{1}{L}\#\{x\in\{0,\ldots,L-1\}:\exists i,\ x\equiv a_i\pmod {n_i}\}.
$$

The main question is to minimize $\mu$, or equivalently maximize the covered density, over all residue choices. The companion question asks whether the *worst* choice, the one with the smallest covered density, is always obtained from one common integer $c$, meaning $a_i\equiv c\pmod {n_i}$ for every $i$. “All $a_i$ equal” does not mean that canonical representatives in different modulus ranges are literally the same number.

The quantifiers matter: the moduli are fixed first, exactly one class is chosen for each, and only then is the periodic density evaluated. The problem is about a finite optimization for each input, not about choosing residues after inspecting individual integers one at a time.

## A small example

Take $A=\{3,6,10\}$. The period is $L=30$, and there are $3\cdot6\cdot10=180$ residue vectors. The following exact calculation checks every one using integer counting and rational arithmetic:

```python
from fractions import Fraction
from itertools import product
from math import lcm

ns = (3, 6, 10)
L = lcm(*ns)

def covered_density(residues):
    covered = sum(
        any((x - a) % n == 0 for n, a in zip(ns, residues))
        for x in range(L)
    )
    return Fraction(covered, L)

values = [(covered_density(a), a)
          for a in product(*(range(n) for n in ns))]
print("L", L, "choices", len(values),
      "min", min(values), "max", max(values),
      "common", covered_density((0, 0, 0)))
```

The reproducible output is `L 30 choices 180 min (2/5, (0, 0, 0)) max (17/30, (2, 4, 9)) common 2/5`. Thus the common-residue choice is worst in this example, while another choice covers $17/30$ of the integers. For the common choice, inclusion–exclusion gives

$$
\frac13+\frac16+\frac1{10}-\frac16-\frac1{30}-\frac1{30}+\frac1{30}
=\frac13+\frac1{10}-\frac1{30}=\frac25.
$$

This is a checked finite illustration of periodic reduction, not evidence for the general theorem.

## What is known

The original source is Erdős and Graham, *Old and New Problems and Results in Combinatorial Number Theory* (1980), p. 28, lines 4–6 of the scanned page. It asks for the minimum density missed by suitable congruences and asks whether the worst choice has all residues equal. The source is a book statement, not a proof of the optimization problem.

The all-equal companion assertion is attributed to R. J. Simpson, “Exact coverings of the integers by arithmetic progressions,” *Discrete Mathematics* 59 (1986), 181–190, DOI [10.1016/0012-365X(86)90079-8](https://doi.org/10.1016/0012-365X(86)90079-8), Lemma 2.3 as cited by later work. The bibliographic record and attribution are verified, but the publisher’s full text was not accessible in this audit; it is therefore reported as a published result cited by the source packet, not as a replayed proof here. Halberstam and Roth, *Sequences* (1983), §5.3, first theorem, is another cited source for a related covering fact; only the publisher’s metadata and chapter description were accessible, so its theorem is likewise not independently verified here.

Stijn Cambie’s accessible arXiv v2, [“Proving it is impossible; on Erdős problem #278”](https://arxiv.org/abs/2508.18270), directly proves a useful structured interface. For the pairwise-distinct moduli $\{3\}\cup\{3p:p\in P\}$, the missed density is claimed and proved there to be

$$
\mu=\frac13\min_{P=P_1\mathbin{\dot\cup}P_2}
\left(\prod_{p\in P_1}\left(1-\frac1p\right)+
\prod_{p\in P_2}\left(1-\frac1p\right)\right).
$$

The proof partitions the two nonzero residue fibers modulo $3$ and applies the Chinese remainder theorem inside each fiber. Cambie also proves NP-hardness of zero missed density for binary-encoded *lists* of moduli, where repetitions are allowed, via Exact Pinwheel Covering. That is not a theorem for the literal pairwise-distinct set version: repeated moduli can choose complementary classes, and deleting repetitions can change the answer.
