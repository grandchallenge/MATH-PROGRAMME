## The question in plain language

A set of integers can have a large *harmonic weight* even when its ordinary counting density is small. For $A\subseteq\mathbb N$, define $H_A(x)=\sum_{n\in A\cap[1,x)}1/n$. Erdős Problem 442 asked whether the condition $H_A(x)/\log\log x\to\infty$ forces the reciprocal-least-common-multiple correlations within $A$ to become arbitrarily large after normalization by $H_A(x)^2$:

$$
\frac{1}{H_A(x)^2}
\sum_{\substack{a,b\in A\cap(1,x]\\a<b}}
\frac{1}{\mathrm{lcm}(a,b)}
\longrightarrow\infty?
$$

The two sums have slightly different endpoint conventions in the historical statement; these are normally negligible in suitable asymptotic regimes, but a formal statement must retain them exactly. The pair sum uses unordered distinct pairs. This is a question about the interaction of additive growth in harmonic weight with multiplicative overlap measured by gcd, since $1/\mathrm{lcm}(a,b)=\gcd(a,b)/(ab)$.

## A small example

Take the finite set $A=\{2,3,6\}$ and an $x>6$. Its harmonic weight is $H_A=1/2+1/3+1/6=1$. All three pairwise least common multiples equal $6$, so the reciprocal-LCM sum is $3/6=1/2$, and the normalized expression is $1/2$. This verifies the exact normalizations and the requirement to count each unordered pair once.

This finite example is not a counterexample to an asymptotic conjecture, because a finite set has bounded harmonic weight. More generally, multiplying the harmonic sum by an arbitrary scale without correspondingly changing the underlying set is not a valid operation: both the numerator and denominator must come from the same $A$. A useful computational fixture sums exact rational numbers, avoiding rounding errors that can obscure close comparisons in finite examples. The identity $\gcd(a,b)/(ab)$ gives a second independent way to calculate each LCM contribution.

## What is known

The original question appears in Erdős and Graham's *Old and New Problems and Results in Combinatorial Number Theory* (1980), printed page 88. The answer is **no**, proved by Terence Tao in 2024, as described in the maintained [Erdős Problems #442](https://www.erdosproblems.com/442) entry.

Tao constructed an infinite set $A$ whose harmonic weight grows at least as fast as

$$
\exp\left((\tfrac12+o(1))\sqrt{\log\log x}\,\log\log\log x\right),
$$

but whose normalized reciprocal-LCM pair correlation remains $O(1)$. This is much stronger than merely exceeding $\log\log x$: it explicitly falsifies the implication from large harmonic weight to divergent normalized correlations.

Tao also established a near-matching threshold: if the harmonic sum grows faster than $\exp(O(\sqrt{\log\log x}\log\log\log x))$ in the precise sense specified by the theorem, the normalized correlation must diverge. Thus the counterexample is coupled to a sharp growth-regime analysis. The distinction between a bounded ratio for one carefully engineered set and forced divergence above a threshold is central to the result.

One implementation should use gcd reduction; another should compute lcm from prime-power maxima. They must agree on every unordered pair and explicitly exclude $a=b$. A small finite calculation cannot settle the growth threshold, so the output must label its horizon.
