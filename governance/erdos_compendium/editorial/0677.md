## The question in plain language

Can the least common multiple of one block of consecutive integers recur in a completely later block of the **same length**? Write $M(n,k)=\mathrm{lcm}(n+1,\ldots,n+k)$. The main [Erdős #677](https://www.erdosproblems.com/677) asks whether $M(n,k)\ne M(m,k)$ whenever $m\geq n+k$. This is still OPEN. The intervals do not overlap, and the number of terms stays fixed.

## A small example

Some **different-length** blocks do have the same least common multiple: $M(4,3)=\mathrm{lcm}(5,6,7)=210=M(13,2)$ and $M(3,4)=\mathrm{lcm}(4,5,6,7)=420=M(19,2)$. These identities, verified by gcd/lcm arithmetic, are not counterexamples because the two blocks have different lengths. Nor does a short-shift decrease, such as $M(6,7)>M(8,7)$, refute the claim: $8<6+7$.

## What is known

For $k=1$ the lcm is $n+1$. For $k=2$ it is $(n+1)(n+2)$ because consecutive integers are coprime. Both strictly increase with $n$, proving non-recurrence for those lengths. The maintained source attributes to the Thue–Siegel theorem that for each **fixed** $k$ there can be only finitely many separated equalities. *Finitely many* is weaker than *none*. A bounded exhaustive scan for $1\leq k\leq7$, $0\leq n\leq100$ and $n+k\leq m\leq150$ found none; this is not an infinite proof. The maintained page also reports a stronger conjecture comparing **prime-factor sets** of two nonoverlapping products, which is a different statement.
