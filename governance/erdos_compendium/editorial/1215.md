## The question in plain language

[Erdős Problem #1215](https://www.erdosproblems.com/1215) currently has source status **DISPROVED — ENDPOINT NORMALIZATION REQUIRED**.

Let $P$ be any polynomial with $P(0)=1$ and **all zeros on the unit circle**. Erdős–Herzog–Piranian asked whether there exists a universal length bound $C$ for a path from the origin to the unit circle **through the sublevel region** $\{z:|P(z)|<1\}$. Literally, $0$ is **NOT in** this strict open sublevel because $|P(0)|=1$. Thus any valid interpretation must permit **the starting point on the boundary**, with the path interior otherwise inside the strict sublevel. Without this endpoint normalization, no such continuous path has its image entirely in the stated open set, a trivial semantic impossibility that should not replace Mac Lane's substantive counterexample.

## A small example

For $P(z)=1-z$ (one root at $z=1$ on the unit circle), $P(0)=1$ and hence the origin lies on the **boundary** of $\{|P|<1\}$. The open real segment $0<t\le1$ satisfies $|P(t)|=1-t<1$, while the starting endpoint $t=0$ has equality. The phase25 fixture evaluates the 11 points $t=0,0.1,\dots,1$. This is one easy path under the boundary-endpoint interpretation, not a universal length bound.

## What is known

The maintained https://www.erdosproblems.com/1215 reports **DISPROVED** as a **uniform bounded-length** assertion by Mac Lane [Ma53]. Cohen [Co52] showed paths can exist for each polynomial; Loewner's example excludes every straight radial segment. Mac Lane's polynomials can force sublevel paths through arbitrarily complicated narrow corridors/labyrinths, so no universal path-length constant works. Repeating a loop is not a counterexample, since one asks for the existence of *some short* path; forcing all admissible paths to be long is essential. The precise labyrinth theorem and '$|P|>2$ on compact $A$' normalization require original-source review.
