## The question in plain language

Find g(n) for which some n-vertex graph has, in EVERY induced subgraph on g(n) vertices, BOTH a clique and an independent set of size >= log n. The existential choice of host G is outside the universal quantifier over induced g(n)-vertex subsets. Question especially asks g(n)=(log n)^3.

The required graph must contain, in each selected g(n)-vertex subset, BOTH a large clique and a large independent set. This is much stronger than a Ramsey disjunction that guarantees one of the two. The known very large construction does not resolve the original cubic-logarithmic target.

## A small example

For empty Kbar4, every induced 3-vertex subgraph contains an independent set of size 3 but a clique of size only 1. For K4 the converse holds: clique of size 3 but independent number 1. Either fixture violates a simultaneous threshold 2. This explains why testing only one of the properties is inadequate.

This finite fixture tests the conventions. It does not certify any of the asymptotic or all-graphs assertions.

## What is known

Maintained #805 OPEN: Erdős–Hajnal expected negative for cubic-log. Alon–Sudakov [AlSu07] rule out g(n)=c (log n)^3/loglog n for a positive c. Alon–Bucić–Sudakov [ABS21] exhibit graphs with g(n) at most 2^(2^((loglog n)^(1/2+o(1)))). The latter is much larger than (log n)^3 asymptotically; it does NOT settle cubic-log. Original 2007 and 2021 proofs remain primary-source obligations.

The distinctions between established partial theorems, original open parts, and disproved universal claims have been preserved. Historical publications are attributed, rather than presented as new GCL mathematics.

The logical order can be written as

$$

\exists G\quad
\forall S\subseteq V(G),\ |S|=g(n):
\quad\alpha(G[S])\geq\log n,\quad
\omega(G[S])\geq\log n.

$$

Here the maximum clique number $\omega$ and maximum independent-set size $\alpha$ must satisfy the condition on the same induced subset. The open challenge concerns $g(n)=(\log n)^3$.
