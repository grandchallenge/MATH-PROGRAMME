## The question in plain language

The maintained #728 asks for infinitely many a,b,n with a,b≥ε n, a! b! dividing n! (a+b−n)! and a+b>n+C log n. AS WRITTEN it is trivial: taking a=b=n gives equality of both factorial products and a+b=2n>n+C log n for sufficiently large n (for fixed ε<1). The intended near-central nontrivial condition a,b≤(1−ε)n and a+b−n≈C log n is not included in that literal statement. The catalogue reports an external Barreto / GPT-5.2 Pro / Aristotle proof of a strengthened version; do not conflate it with the trivial literal existence.

## A small example

For any n≥2 take a=b=n: a!b!=n!n! and n!(a+b−n)!=n!n!, so divisibility holds exactly. If 0<ε≤1, both lower conditions hold. For fixed C>0, n>C log n eventually, hence a+b=2n>n+C log n. This supplies infinitely many literal examples without invoking the external theorem, but does not address a,b≈n/2.
