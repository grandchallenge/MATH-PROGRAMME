## The question in plain language

Suppose every three-element subset of the continuum is colored red or blue. Erdős #70 asks whether, for *every* countable ordinal $\beta$ and *every* finite $n\ge2$, one necessarily gets either a red homogeneous set of order type $\beta$, or a blue homogeneous set of cardinality $n$. Its conventional partition notation is

$$
\mathfrak c\to(\beta,n)^3_2.
$$

Order type matters. The order $\omega+1$ has infinitely many increasing points followed by a final point; it is not order-isomorphic to $\omega$.

## A small example

For $n=2$ the blue alternative is vacuous: a two-element set has no triples. For $n=3$, either some triple is blue or every triple is red. In the second case the initial ordinal $\mathfrak c$ contains every countable order type. This proves the problem for $n\le3$ without higher set theory.

Another helpful example is $\omega+\omega+1$, two infinite ordered blocks followed by a final element. Adding one further endpoint gives $\omega+\omega+2$. The apparently small difference exposes a significant boundary in existing partition theorems.

## What is known

The overall problem remains **OPEN**. Albin L. Jones proved in 2018 that

$$
\omega_1\to(\omega\cdot2+1,n)^3_2
\qquad(n<\omega).
$$

Every coloring on $[\mathfrak c]^3$ restricts to $[\omega_1]^3$ because $\omega_1\le\mathfrak c$. Thus Jones's theorem proves the continuum statement whenever $\beta\le\omega\cdot2+1$. Coupled with the trivial finite alternatives, cases with $n\ge4$ and $\beta\ge\omega\cdot2+2$ are not covered by these arguments. This description does *not* establish that every parameter pair in the remaining region is independently open.

The 2018 source gives a stronger theorem than elementary infinite Ramsey theory, whose homogeneous subsets need not have such prescribed ordinal order type. GCL has not independently checked the forcing arguments in the full paper.

## What remains

A bounded successor is to state a precise candidate two-orientation cross-triple lemma for blocks $A<B$ and test it against finite colorings before attempting $\omega\cdot2+2$. Every hypothesis on color, triple orientation, cardinality, and order must be recorded; neither a finite successful test nor the 2018 result automatically establishes the next ordinal case. Full primary Proposition 5.2 page checking and protected Lean statement fidelity remain outstanding.
