## The question in plain language

For all sufficiently large n, Erdős asks for a NONTRIVIAL pairwise balanced block design on n vertices, each vertex pair in exactly one block, with at most O(√n) blocks of EACH size t. This is OPEN. Big-O must be uniform over t and sufficiently large n. Define c_t=#blocks of size t.

## A small example

In the seven-point Fano design, the seven blocks all have size three, so c₃=7 and $\sum_t c_t\binom{t}{2}=7\cdot3=21=\binom{7}{2}$. This finite example cannot prove the asymptotic result. The design using all n choose 2 pairs as two-element blocks is a trivial linear space with $c_2=\binom{n}{2}$, which fails the desired O(√n) frequency.

## What is known

Pair counting gives the necessary identity $\sum_t c_t\binom{t}{2}=\binom{n}{2}$. Its satisfaction alone does not construct an incidence design. The maintained source cites de Bruijn–Erdős's lower bound m≥n for nontrivial linear spaces, subject to its exact hypotheses, and quotes Erdős's unproved expectation from [Er81,p.35]. No general construction meeting the multiplicity bound is source-verified.
