## The question in plain language

Ramsey completeness means that any finite coloring of the infinite set leaves one color class whose distinct-element subset sums represent all sufficiently large integers. The theorem for powers is substantially stronger than finding just one large monochromatic sum.

A set of positive integers S is Ramsey r-complete if EVERY coloring S with r colors has at least one color class whose subset sums of DISTINCT elements contain all sufficiently large positive integers. Ask for S consisting of square numbers, and separately kth powers with r,k>=2. This is about all sufficiently large targets, not merely arbitrarily large representable targets.

## A small example

For squares {1,4,9}, the distinct-element subset sums are {0,1,4,5,9,10,13,14}. Target 2 is missing; this is expected because Ramsey completeness is an eventually-all-integers statement on an INFINITE colored sequence. Any finite initial segment must miss sufficiently large integers.

A finite instance tests the definition, not a claim quantified over every large graph, infinite set or arbitrary coloring.

## What is known

Maintained https://www.erdosproblems.com/latex/843 read 2026-10-14: Burr's result for powers mentioned by Erdős in 1995 was unpublished. Conlon–Fox–Pham [CFP21], *Subset sums, completeness and colorings*, arXiv:2104.14766 (2021) proved a STRONGER theorem including sparse Ramsey r-complete subsequences of kth powers for all r,k>=2. Full original proof and sparseness conditions not independently verified; do not treat unpublished Burr note as primary proof.

Let FS(C) denote all sums of finite subsets of C, with each summand used at most once. Ramsey r-completeness asks that for every coloring there exist a color class C and an integer N0 such that EVERY integer at least N0 belongs to FS(C). It does not ask for every color class to be complete, nor for a finite initial prefix to represent every number. Conlon, Fox and Pham report a stronger sparse-subsequence theorem.
