## The question in plain language

For EVERY nonnegative function f(m)→∞, must there exist one graph G of infinite chromatic number such that every m-vertex subgraph contains an independent set of size at least m/2−f(m)? The frozen 2025 catalogue labels the problem PROVED, and the GCL-pinned FormalConjectures #750 records answer(True), and the current maintained page now explicitly reports a GPT-5.5 Pro solution prompted by Chojecki. This is not equivalent to a GCL proof certificate. This discrepancy is material. Do not promote a pinned `answer(True)` annotation with a `sorry` proof body to verified GCL mathematical certification.

## A small example

The odd cycle C_5 has chromatic number three. Removing one vertex leaves a path on four vertices, so any induced subgraph on m≤5 vertices has an independent set of size at least floor(m/2). In particular the full C5 has α(C5)=2≥5/2−1. This finite example does not have INFINITE chromatic number and cannot decide the theorem.

## What is known

Erdős, Hajnal and Szemerédi [EHS82] prove the weaker, linear-error formulation for every fixed ε>0: one can arrange α(H)≥(1/2−ε)|V(H)| in all finite induced H while maintaining infinite chromatic number. That corresponds to f(m)=εm, much larger than an arbitrary slowly divergent f(m) such as logloglog m. The GCL-pinned #750.lean at 85f863718beeec7b58a3a1926ee92e3472bc2020 contains the main arbitrary f theorem with `answer(True)` but `by sorry`, plus ε and c>1/4 auxiliary variants also sorry. The currently reported model-assisted construction and its Lean sketch require independent scrutiny; the external sketch reportedly assumes Stiebitz's theorem as an axiom and the GCL-pinned main proof body is still unproved.
