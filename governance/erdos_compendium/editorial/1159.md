## The question in plain language

[Erdős Problem #1159](https://www.erdosproblems.com/1159). Does one constant work for every finite projective plane, guaranteeing a point set that touches every line but does not put too many chosen points on any line?

$$
1\le |S\cap\ell|\le C\quad\text{for every line }\ell\text{ of every finite projective plane}.
$$

For every FINITE projective plane P of arbitrary order q (not just Desarguesian prime-power planes), ask if there exists an ABSOLUTE constant C>1 independent of q and P and some point set S such that EVERY line ℓ satisfies 1≤|S∩ℓ|≤C. Such S is a line-hitting/blocking set with UNIFORMLY bounded intersection. Standard 'blocking set' definitions sometimes exclude an entire line; the mathematical condition stated here does NOT. Check degenerate q and possible non-Desarguesian planes; this is not a finite-computation-decidable universal statement.

## A small example

Construct PG(2,2) (Fano) and PG(2,3) as one-dimensional projective classes of nonzero vectors in F_q^3, with lines orthogonal to nonzero linear forms. Exhaustive enumeration of ALL point subsets verifies minimal feasible largest line intersection C_min=3 for q=2 and also C_min=3 for q=3. Fano has NO 2-colourable point partition with every line nonmonochromatic, so C=2 fails; choosing one complete Fano line gives C=3 (self-intersection 3, any other line intersection 1). q=3 enumeration finds 6-point S meeting each 4-point line between 1 and3. This finite evidence does not establish any universal q-independent C or treat non-Desarguesian projective planes.
