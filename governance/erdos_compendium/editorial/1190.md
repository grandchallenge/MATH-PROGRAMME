## The question in plain language

[Erdős Problem #1190](https://www.erdosproblems.com/1190) is **EXTERNAL SOLVED — FORMAL FIDELITY PENDING** in the maintained catalogue.

For an integer threshold $m$ let $\epsilon_m$ be the supremum of reciprocal-modulus sums $\sum_i1/n_i$ over finite strictly increasing $m<n_1<\dots<n_k$ for which there are congruence classes $a_i\bmod n_i$ that are **pairwise disjoint** (no integer satisfies two). Unlike a covering system, these classes **avoid overlap** rather than cover the integers. Define $L(m)=\exp(\sqrt{\log m\,\log\log m})$. Determine the asymptotic scale of $\epsilon_m$ as $m\to\infty$.

## A small example

The classes $0\bmod4$ and $1\bmod6$ never intersect: a common integer would be simultaneously even and odd modulo $\gcd(4,6)=2$. Their reciprocal sum is $1/4+1/6=5/12$. This is an exact Chinese-remainder compatibility example only, not a sharp estimate for large $m$; this pair is valid only when the cutoff is below 4.
