## The question in plain language

For every n-element set A of integers, let f(n) be the minimum over A of the maximum size of a subset B with no solution a+b=c in B; repeated summands a=b are INCLUDED unless expressly excluded. Estimate f(n), particularly surplus over n/3.

The key is to preserve the order of the quantifiers and the exact distinction between a finite example and a theorem about arbitrary large inputs. Replacing an extremum over every admissible set by an extremum over one convenient set would change the problem.

## A small example

For A={1,2,3}, B={2,3} is sum-free (neither 2+2 nor 2+3 nor 3+3 is in B), size two. B={1,2} is NOT sum-free because 1+1=2. The repeated-summand clause matters.

The calculation illustrates the exact definitions and hypotheses. No single finite example establishes the reported asymptotic assertion.
