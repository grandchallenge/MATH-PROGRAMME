## The question in plain language

Can one construct an additive basis of order two **explicitly**, while ensuring that no integer has very many representations? [Erdős Problem #29](https://www.erdosproblems.com/29) asks for a single computably described set $A$ of nonnegative integers with

$$
A+A=\mathbb N,\qquad
r_A(n)=o(n^\varepsilon)\quad\text{for every }\varepsilon>0,
$$

where $r_A(n)$ counts ordered pairs from $A$ summing to $n$. The problem is **solved**.

This differs from Problem #28: subpolynomial growth still permits representation counts that increase without bound. It also differs from proving existence by a random construction.

## A small example

Because $0\in A+A$, any such set must contain 0. Then, to represent 1, it must contain 1 as well. The finite example $A=\{0,1,2\}$ represents every integer from 0 through 4, with ordered counts $1,2,3,2,1$.

That finite success gives no assurance of representing 5 or any larger integer. An actual explicit infinite basis needs a coherent membership rule and a proof covering **all** nonnegative targets.

## What is known

Jain, Pham, Sawhney and Zakharov, *An explicit economical additive basis* (2024), give an explicit construction answering Erdős's question affirmatively. Earlier probabilistic work by Erdős established the existence of economical bases, but an explicit construction was a separate outstanding challenge.

The published construction establishes small representation counts in the subpolynomial sense required by the problem; it does **not** prove representations can be bounded by one fixed constant, which would be relevant to the open Problem #28.

## GCL's current state

[Source audit #1298](https://github.com/grandchallenge/MATH-PROGRAMME/issues/1298#issuecomment-6121318190) compares the explicit and probabilistic claims, checks the zero-element boundary and proposes a pinned finite-prefix replay of the published construction. The complete source proof and any externally reported formalization have not been kernel-replayed under GCL controls.

## What remains

Nothing remains to resolve the historical explicit-construction question. A useful separate task is to implement the authors' actual membership algorithm with deterministic witness tests and a reproducible formal proof of its asymptotic bound.
