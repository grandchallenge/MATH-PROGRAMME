## The question in plain language

[Erdős Problem #1208](https://www.erdosproblems.com/1208) currently has source status **OPEN SHARP EXTREMAL BOUNDS**.

For fixed $d\ge2$, $F_d(n)$ is the largest integer guaranteed so that **every** set of $n$ points in $\mathbb R^d$ contains an $F_d(n)$-point subset with **all unordered pairwise distances distinct**. It is a min–max over configurations, not a maximum for just a lattice. This is stronger than merely avoiding isosceles triangles (#1207), since distances belonging to **disjoint** pairs must also differ.

## A small example

Exhaustively checking all $512$ subsets of the $3\times3$ integer grid yields **86** subsets with all pairwise distances distinct, of maximum size **three**. A witness $\{(0,0),(0,2),(1,0)\}$ has squared distances $4,1,5$. This is exact for one nine-point configuration, **not** the universal value of $F_2(9)$ or a bound for all $n$.

## What is known

The maintained source https://www.erdosproblems.com/1208 remains **OPEN** for sharp bounds. In the plane, Charalambides [Ch13] and September 2026 Lee–Pohoata–Zhu [LPZ26] give $n^{1/3}/(\log n)^{1/3}\ll F_2(n)\ll n^{1/2-c}$ for some $c>0$. For $d\ge3$ Conlon–Fox–Gasarch–Harris–Ulrich–Zbarsky [CFGHUZ15] improve Thiele to $F_d(n)\gg_d n^{1/(3d-3)}(\log n)^{1/3-2/(3d-3)}$; integer lattices show $F_d(n)\ll n^{1/d}$. LPZ26 original proof not independently verified.
