## The question in plain language

[Erdős Problem #1173](https://www.erdosproblems.com/1173) is classified **OPEN — MANDATORY CRITICAL** in the maintained catalogue.

Assume the **generalized continuum hypothesis**. Let $\mu=\aleph_\omega$ (a **singular** cardinal of countable cofinality) and $\kappa=\mu^+=\aleph_{\omega+1}$. A set mapping

$$
f:\kappa\longrightarrow[\kappa]^{\le\mu}
$$

has $|f(\alpha)\cap f(\beta)|<\mu$ for every distinct $\alpha,\beta$. Does there exist a **free set** $H\subseteq\kappa$ of cardinality $\kappa$, meaning for all distinct $\alpha,\beta\in H$ we have $\beta\notin f(\alpha)$ **and** $\alpha\notin f(\beta)$? Standard literature may also require $\alpha\notin f(\alpha)$ for every $\alpha$; deleting possible self-incidence normalizes it. Crucially, the pairwise $<\aleph_\omega$ condition does **not** imply a uniform bound $<\nu$ for any fixed $\nu<\aleph_\omega$.

## A small example

For the **eight-cycle** mapping $f(i)=\{i+1\bmod8\}$, each image has size one and distinct images have intersection zero; $\{0,2,4,6\}$ is free. Exhaustive search over all $256$ subsets finds that the **largest free set has size four**, with two such largest sets. The empty mapping instead makes all eight elements free. This shows that small pairwise intersections do not make the entire finite universe free. It is **not a counterexample** to existence of a free set of size $\kappa$ under GCH.
