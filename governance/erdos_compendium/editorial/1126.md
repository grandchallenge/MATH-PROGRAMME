## The question in plain language

A function $g:\mathbb R\to\mathbb R$ is **additive** when

$$
g(x+y)=g(x)+g(y)
$$

for every pair of real numbers. [Erdős Problem #1126](https://www.erdosproblems.com/1126) asks whether a function $f$ satisfying this identity for **almost every pair** $(x,y)\in\mathbb R^2$ must agree almost everywhere on $\mathbb R$ with some exactly additive $g$.

The answer is **yes**. The distinction between a null set of *pairs* in the plane and a null set of individual real values is essential.

## A small example

Define $f(x)=2x$ except $f(0)=7$. The function $f$ is not exactly additive, but the equation can fail only when $x=0$, $y=0$ or $x+y=0$. These are three lines of **planar measure zero**.

Setting $g(x)=2x$ repairs the function: $g$ is additive everywhere and agrees with $f$ except at zero, a one-dimensional null set.

Exact rational-grid arithmetic finds thirteen failures among 36 test pairs, all on those three lines. This finite grid cannot reflect continuous measure directly.

## What is known

**Jurkat (1965)** and **de Bruijn (1966)** independently proved the general almost-everywhere Cauchy-equation result. Neither the original premise nor the repaired additive representative requires a conventional measurability assumption on $f$.

The maintained catalogue reports an external Lean proof, but the GCL-pinned file contains a placeholder and links outside the frozen source. Its complete kernel proof has not been replayed.
