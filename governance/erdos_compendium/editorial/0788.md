## The question in plain language

An adversary supplies a set of forbidden sums in an upper integer interval. We then select numbers in a lower interval, avoiding forbidden distinct-pair sums, and measure the worst-case total size of both sets.

Let f(n) be the greatest lower guarantee such that for EVERY B subset (2n,4n)∩N there exists C subset (n,2n)∩N with no sum c1+c2 in B for distinct c1,c2 in C, and |B|+|C|>= f(n). Thus f(n)=min_B (|B|+alpha(G_B)), where G_B is the graph on admissible middle integers with edge {c1,c2} whenever c1+c2 in B. The 'for every B' quantifier is ESSENTIAL; f(n) is not the maximum for a favorable choice of B.

## A small example

For n=3 the eligible lower integers are 4,5, whose only distinct pair sum is 9. If 9 is forbidden we can select at most one; otherwise we can select both. The exact worst-case total is two.

Finite example n=3: middle integers (3,6)={4,5}, B ranges subsets of (6,12)={7,8,9,10,11}. Only distinct-pair sum is 4+5=9. If 9 in B then max |C|=1; otherwise |C|=2. The function of B can be enumerated exactly: min(|B|+alpha)=2 attained for B empty or {9}. No theorem about all n follows.
