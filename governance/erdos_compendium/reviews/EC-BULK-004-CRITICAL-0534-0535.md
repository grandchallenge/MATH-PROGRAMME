## #534 SOLVED — Erdős–Graham gcd-intersecting family, 1996 Ahlswede–Khachatrian

Original Erdős, *Problems and Results on Combinatorial Number Theory*, *A Survey of Combinatorial Theory* (1973) Chapter12 printed p123 / PDF page index6, https://www.renyi.hu/~p_erdos/1973-21.pdf#page=7 DIRECTLY visually inspected, primary PDF retained CHAD /tmp/ec004-er1973-0534-0535.pdf. The original prints (a_i,a_j)=1, while a Graham–Erdős common-prime divisor extremum, modern https://www.erdosproblems.com/534, corrects it to gcd(a_i,a_j)>1 for DISTINCT elements and requires N in A⊆[1,N]. The 1973 second numerical candidate counts even 2t with (t,N)=1 whereas maintained page writes (2t,N)>1; do NOT equate these variants. The initial conjecture 'maximum either N/p or the count of particular even 2t' was counterexampled (Ahlswede–Khachatrian report notifying Erdős in 1992). Refined extremal theorem reported by maintained catalogue: if q1<...<qr are DISTINCT prime divisors of N, set D_j={2q1,...,2qj,Q_j}, Q_j=q1...qj, A_j={x∈[1,N]:∃d∈D_j,d|x}. Then M(N)=max_(1≤j≤r)|A_j|. Check EACH A_j includes N and all pairs non-coprime: two 2q factors share 2; Q_j and 2qi share qi. For even N, A1 contains all even x; for prime N, A1={N}. The nontrivial direction M(N)≤max_j|A_j| is 1996 theorem, NOT proved by finite examples.

## #535 OPEN — equal pairwise gcd, layer-sunflower map and current subpolynomial bound

Original Erdős, *On a Problem in Elementary Number Theory and a Combinatorial Problem*, Math. Comput. 18 (1964) 644–646, COMPLETE primary 3-page PDF https://www.renyi.hu/~p_erdos/1964-10.pdf CHAD retained /tmp/ec004-er1964-0534-0535.pdf, original page1 visually inspected; 1973 Chapter12 p123 same original survey direct screenshot. For fixed r≥3 modern f_r(N)=MAX size A⊆[1,N] such that no r DISTINCT chosen integers have ALL pairwise gcd=d equal for ANY d≥1. Note original 1964 function was MIN size forcing pattern, so forcing value = modern f_r(N)+1. Erdős proved exp(c_r log N/loglog N) lower and N^(3/4+o(1)) upper, Abbott/Hanson *An extremal problem in number theory*, Bull Lond Math Soc 2 (1970) 324–326 DOI 10.1112/blms/2.3.324 improved historical upper to N^(1/2+o(1)), but this is NOT CURRENT best bound. Maintained catalogue https://www.erdosproblems.com/535 last edited 2026-04-29 OPEN gives f_r(N)≤exp(O_r(log N logloglog N/loglog N))=N^o(1) using modern sunflower bounds and appropriate bounded-size refinements. Conjecture still asks f_r(N)≤exp(C_r log N/loglog N) (NO logloglog loss).

1973 SOURCE QUALIFICATION: Abbott warns ordinary sunflower conjecture does not seem to imply arithmetic conjecture; stronger auxiliary version fixes Ω(n)=k, factors WITH multiplicity, and forbids r equal-gcd numbers with extra gcd(a_i/d,d)=1 condition.
