## #541 — PROVED, Graham's unique zero-sum subsequence length

Original Erdős same 1973 chapter12 printed p126, https://www.renyi.hu/~p_erdos/1973-21.pdf#page=10 original screenshot visually inspected. Sequence of exactly n indexed residues a_1,...,a_n modulo n, RESIDUES MAY REPEAT, index subsets nonempty and all zero-sum index subsets have ONE size r. Then at most TWO different residue values occur. Erdős credits R. L. Graham; original prime-modulus question. P. Erdős/E. Szemerédi, *On a problem of Graham*, Publ. Math. Debrecen 23 (1976) 123–127, proved for sufficiently large primes as stated in full later primary. Gao/Hamidoune/Wang, *Distinct Length Modular Zero-sum Subsequences: A Proof of Graham's Conjecture*, J Number Theory 130(6) (2010) 1425–1431 DOI 10.1016/j.jnt.2009.11.012, FULL original 9-page arXiv:0902.4758v1 CHAD /tmp/ec004-gao-0540-0541.pdf fetched; Theorem1.1 PDF p2 visually verified, all positive moduli including composite and zero entries allowed. Detailed proof relies on maximal multiplicity Lemma B and long zero-sum-free sequences Theorem D, splits r≥n/2 vs r<n/2; structure directly inspected, complete proof not independently rederived.

Simple non-vacuity lemma: n prefix sums modulo n either contains zero, or duplicates among n−1 nonzero residues; gives nonempty contiguous zero-sum subblock. Exact finite length set L(a)={|S|:∅≠S⊆[n], Σ_(i∈S)a_i=0 modn}; conclusion |L(a)|=1⇒|{a_i}|≤2. Example all n ones L={n}; example one zero with n−1 ones L={1} and two values for n≥2. These are indexed sequences; merging repeated entries into a set changes the problem.
