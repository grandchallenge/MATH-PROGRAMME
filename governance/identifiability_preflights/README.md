# Identifiability preflights

This directory contains MATH-PROGRAMME records created under the adopted GCL-ID-00 v0.1.0 profile.

Create a JSON record here only when the work package is in scope under `governance/GCL-ID-00-ADOPTION.json`. Ordinary forward work and exploration without a material reconstruction claim do not need a record.

Records validate against `schemas/identifiability_preflight.schema.json`.

The default level is `ID-PREFLIGHT-LITE`. `UNRESOLVED` is valid. Do not manufacture an injectivity proof to satisfy the preflight.

Completed records count prospectively toward the 8–12 package observational review window. VGSE-ENG-WP06 is historical motivation and is not counted.
