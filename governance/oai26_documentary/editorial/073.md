# OAI-26 family 073: Falconer's distance conjecture

**Editorial status: DRAFT_UNACCEPTED. Mathematical status: NO_CERTIFICATION.**

## The question in plain language

How large must a fractal point set be before its collection of pairwise Euclidean distances occupies a set of positive length?

## A small example

A planar line segment determines every distance from zero up to its length. The difficult cases are irregular fractal sets with no segments.

## What is known

The pinned manuscript claims that for every integer dimension $d\ge 2$, a compact set $E$ in Euclidean $d$-space with Hausdorff dimension strictly greater than $d/2$ determines a distance set of positive one-dimensional Lebesgue measure. Its introduction explicitly excludes an endpoint or sharp pinned-distance claim. The described proof uses directional cap bounds, multiscale profiles, oscillatory graph reductions and Fourier-shell reconstruction. These remain **publisher claims**, not GCL-certified theorems.
