# OAI-26 family 128: factor-two shortest-common-superstring approximation

**Editorial status: DRAFT_UNACCEPTED. NO_CERTIFICATION.** This source-pinned documentary record reports the publisher's claimed theorem; it does not independently verify the algorithm.

## The question in plain language

Given several strings, find the shortest single string containing every input as a contiguous substring. The shortest common superstring problem rewards reuse of overlapping prefixes and suffixes, but selecting overlaps globally can be difficult.

Family 128 claims a deterministic polynomial-time algorithm producing a superstring no longer than twice the optimum.

## A small example

The strings ABCD and CDEF can be combined into ABCDEF, reusing their common CD overlap. Simply concatenating the inputs instead would require eight characters rather than six. When many strings are involved, optimizing one local overlap may prevent a better global arrangement.

If the minimum feasible length is $L^\ast$, a factor-two approximation promises a constructed string $S$ with $|S|\le 2L^\ast$. The output must contain each input as a contiguous substring, not merely as a subsequence.

## What is known

The protected Family 128 catalogue identifies one manuscript, *A Polynomial-Time 2-Approximation for Shortest Common Superstring*.

The pinned publisher overview claims that for **every finite family of explicitly represented strings**, a **deterministic polynomial-time** algorithm constructs a common superstring satisfying

$$
|S|\le 2\,\operatorname{OPT}(\mathcal F),
$$

where $\operatorname{OPT}(\mathcal F)$ is the least achievable superstring length.

The overview specifies running time polynomial in the **full encoded input length, including symbol labels**. This qualification matters when the alphabet is variable; symbol operations cannot be treated as free without accounting for their encoding.

The claimed result is an approximation upper bound, not proof that factor two is optimal or an exact polynomial-time algorithm.
