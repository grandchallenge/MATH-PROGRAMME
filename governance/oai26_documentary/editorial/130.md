# OAI-26 family 130: exact discrete Fourier transforms below n log n

**Editorial status: DRAFT_UNACCEPTED. NO_CERTIFICATION.** This account documents a pinned publisher claim; it does not independently verify an algorithm or arithmetic complexity bound.

## The question in plain language

The discrete Fourier transform (DFT) reorganizes a sequence of numbers into its frequency components. The standard fast Fourier transform evaluates a length $n$ DFT in order $n\log n$ arithmetic operations. Family 130 claims a deterministic exact-arithmetic algorithm that saves a small but genuine power of the logarithm.

The issue is not numerical approximation: the asserted construction computes the transform exactly in a specific algebraic computation model.

## A small example

For an input vector $(x_0,\ldots,x_{n-1})$ and a primitive root of unity of order $n$ $\omega$, its DFT has entries

$$
X_k=\sum_{j=0}^{n-1}x_j\omega^{jk},\qquad 0\le k<n.
$$

Direct evaluation takes order $n^2$ arithmetic operations. An FFT reuses intermediate expressions to reach approximately $n\log n$. The source claims an asymptotic improvement, not merely a faster constant factor for selected lengths.

## What is known

The protected Family 130 catalogue identifies two manuscripts, *An explicit power saving for the exact discrete Fourier transform* and *Finite tensor savings and exact Fourier circuits*.

The pinned publisher overview claims that **for every input length** $n$, a deterministic algorithm computes the exact length $n$ DFT using

$$
O\!\left(n(\log n)^{1-\delta}\right),\qquad \delta=10^{-13},
$$

operations. The stated computation model permits **exact complex arithmetic**, **unrestricted coefficients**, and a **supplied root of unity**. The overview explicitly counts scalar preparation and logarithmic-word indexing.

Because the exponent saving is extremely small, it would not necessarily yield a practical speedup at ordinary input lengths. Its mathematical significance, if established, is crossing the asymptotic $n\log n$ benchmark within the stated model.

The result must not automatically be translated into a Turing-machine bit-complexity improvement: exact complex numbers and unrestricted coefficients can conceal representation costs absent a specified bit model.
