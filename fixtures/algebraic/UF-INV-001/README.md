# UF-INV-001: Inverse-variable implication fixture

## Source claim

For every field extension `K` of `QQ` and every `x` in `K`:

```text
x^2 = 1 and x != -1  implies  x = 1.
```

The fixture is intentionally elementary. Its purpose is to exercise the full
claim and certificate path, including an inequation that cannot be silently
dropped.

## Semantic correspondence

Because `K` is a field:

```text
x != -1
  iff x + 1 != 0
  iff there exists t with t(x + 1) = 1.
```

The source hypotheses are compiled into:

```text
g1 = x^2 - 1
g2 = t(x + 1) - 1.
```

This step is a human proof claim, `UF-INV-001-C001`. The exact polynomial
checker does not certify it.

## Exact certificate

The target `x - 1` belongs to the ideal generated by `g1` and `g2` because:

```text
x - 1 = t*g1 + (1 - x)*g2.
```

`ci/check_algebraic_fixture.py` parses the serialized sparse polynomials,
performs exact rational addition and multiplication, and checks the identity
coefficient by coefficient. It does not call a computer algebra system.

## Claim boundary

- `UF-INV-001-C001`: semantic correspondence, human proved, not formalized.
- `UF-INV-001-C002`: polynomial identity, independently checked exactly.
- `UF-INV-001-C003`: source implication, audited human proof depending on both.

The source implication is deliberately not labelled `CERTIFIED`. Kernel
certification would require importing both the encoding and witness into a
proof assistant and checking their connection to the theorem.

## Adversarial tests

The test suite rejects:

- an altered witness coefficient;
- a changed variable order;
- a duplicate monomial;
- a missing compiled equation;
- a false artifact hash;
- premature promotion of the source implication to `CERTIFIED`.
