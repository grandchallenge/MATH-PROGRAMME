# Showcase

## The programme in one screen

MATH-PROGRAMME is the public front door for a three-pillar research discipline:

```text
MATHFORGE  ->  MATHSOLVE  ->  MATHCERT
discover       organize       certify
```

The aim is not to sound impressive. The aim is to make mathematical work cumulative, inspectable, and difficult to fool.

## The central transformation

| Stage | Question | Artifact |
| --- | --- | --- |
| Curiosity | What might be worth studying? | lead note |
| Reconstruction | What was actually asked? | source map |
| Campaign | What exact obligation can be attacked? | Work Package |
| Evidence | What computation or proof attempt exists? | ledger |
| Handoff | What can be checked? | certification packet |
| Certification | What crossed the proof boundary? | checked artifact |

## The first cross-pillar lane

The first explicit lane is the algebraic witness-to-certificate lane:

```text
small polynomial obligation
  -> external witness search
  -> explicit certificate
  -> Lean/exact replay
  -> local lemma
  -> larger theorem spine
```

This is deliberately not a promise that Gröbner bases solve open problems. It is a disciplined way to use symbolic algebra without walking into worst-case complexity traps.

## What the site teaches

- how to separate discovery from proof;
- how to write a Work Package that teaches the reader;
- how to keep a claim ledger honest;
- how to treat expensive symbolic methods as bounded lanes;
- how to promote a claim only after certification.

## Review posture

A reviewer should be able to say:

> I know what is proved, what is computed, what is conjectural, what failed, and what must happen next.
