## Authorized non-destructive successor mechanism

Each derivative is added only at a distinct new path under docs/historical_math_readers/ in an ordinary branch and protected pull request. The six pinned source paths and their Git blob identities are never overwritten, moved, reformatted or replaced by this workflow.

Each derived reader must contain:

- A visible **DERIVATIVE READING EDITION; NOT AUTHORITATIVE SOURCE** notice, original repository path, exact original blob SHA-1, protected baseline commit and source permalink.
- An explicit source-line-to-derived-location map for every affected formula and any editorial transformations; copy only faithful source material, not new mathematical interpretations.
- A formula-body preservation manifest. Delimiter changes for GitHub/MkDocs compatibility may be mechanical; operator-macro substitutions require separate verified equivalence. - Retention of the original versioned record. No automatic migration of downstream authority references to the derived reader.
