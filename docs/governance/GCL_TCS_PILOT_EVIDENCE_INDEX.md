## Revalidation rule

Revalidation escalates only when a material object changes: normative/authority bytes, relevant workflow/controller/protection state, mathematical/certification/canonical state, evidence-bearing cross-domain authority bridges, C04-C07 capability, constitutional policy, security-sensitive controls, or reserved external claim/publication authority.
