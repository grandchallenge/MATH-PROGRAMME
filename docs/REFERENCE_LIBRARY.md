## Finding the right material

For the current state of research, start with [Current Research](CURRENT_WORK.md) or [Research and Results](SHOWCASE.md). For mathematical questions, see the [Mathematical Estate](domains/index.md) and [Erdős Compendium](erdos/index.md); for readable books, use the [Documentary Library](documentaries/index.md).

All earlier web documents retain their original addresses and remain reachable through the indexes above or the site search. **Removing an item from the navigation does not retire, delete, revise or validate it.** Historical statements must still be read with their original dates and proof qualifications.

The [repository document guide](REPOSITORY_DOCS.md), indexed under Mathematical Methods, links to canonical source records kept in GitHub rather than on the rendered website.
