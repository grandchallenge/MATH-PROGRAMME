# MATH-PROGRAMME Agent Council

The previous Minderling model is retired.

The programme now uses the formal Agent Council defined in:

`docs/MATH_PROGRAMME_AGENT_COUNCIL.md`

The council is the governance model for mathematical production across MATHFORGE, MATHSOLVE, and MATHCERT.

It replaces mnemonic companions with explicit responsibility boundaries:

- mathematical foundations;
- discovery and experimentation;
- dependency architecture;
- verification and adversarial review;
- formal certification;
- exposition and communication;
- provenance;
- implementation;
- publication readiness.

The council exists to ensure that every artifact has:

1. a defined object;
2. a mapped dependency structure;
3. an honest evidence boundary;
4. a verification route;
5. a readable explanation;
6. a path toward implementation or certification.

Binding principle:

> Rigorous mathematics requires not only proof, but a disciplined process that creates, challenges, explains, and preserves the proof.
