# Agent Council Work Package Checklist

Every MATHSOLVE Work Package should carry an Agent Council review record before promotion to certification.

The purpose is not to replace mathematical judgment. The purpose is to make responsibility boundaries explicit: who checked what, what remains unresolved, and what prevents promotion.

## Artifact identity

- [ ] Work Package ID assigned.
- [ ] Domain and pillar ownership declared.
- [ ] Claim type recorded.
- [ ] Certification route identified.

## Axiomatist

- [ ] Carrier object identified.
- [ ] Ambient structure declared.
- [ ] Regularity assumptions recorded.
- [ ] Foundation profile attached.

## Prospector

- [ ] Mathematical motivation recorded.
- [ ] Candidate generalizations considered.
- [ ] Related structures or analogies documented.

## Experimentalist

- [ ] Computational probes recorded.
- [ ] Finite cases or examples tested where appropriate.
- [ ] Failed experiments preserved as evidence.

## Cartographer

- [ ] Dependency graph established.
- [ ] Definitions precede use.
- [ ] Theorem/result inventory exists.
- [ ] Proof obligations are ordered.

## Verifier

- [ ] Claims have precise hypotheses.
- [ ] Proof obligations discharged or explicitly tracked.
- [ ] Quantifiers and edge cases checked.

## Adversary

- [ ] Counterexamples searched.
- [ ] Hidden assumptions reviewed.
- [ ] Overclaiming risks documented.

## Formalist

- [ ] Formalization boundary identified.
- [ ] Machine-checkable targets recorded where applicable.
- [ ] Proof artifacts have provenance.

## Steward

- [ ] Intended reader defined.
- [ ] Motivation is explicit.
- [ ] Examples support understanding.

## Composer

- [ ] Artifact is segmented into readable units.
- [ ] Each segment has a clear purpose.
- [ ] Transitions preserve reader state.

## Grammarian

- [ ] Notation is consistent.
- [ ] Symbols are necessary.
- [ ] Displays are integrated into prose.
- [ ] Sentences remain mathematically grammatical.

## Archivist

- [ ] Prior art reviewed.
- [ ] Citations recorded.
- [ ] Provenance trail maintained.

## Mechanist

- [ ] Implementation implications considered.
- [ ] Reproducibility path documented.
- [ ] Executable artifacts linked where relevant.

## Typesetter

- [ ] Figures and tables clarify structure.
- [ ] References and navigation are complete.
- [ ] Final presentation supports review.

## Referee

- [ ] Contribution boundary is clear.
- [ ] Claims match evidence level.
- [ ] External-review objections anticipated.

## Promotion gate

Before moving from MATHSOLVE toward MATHCERT:

- [ ] No unresolved critical obligations remain.
- [ ] Claim ledger updated.
- [ ] Evidence route declared.
- [ ] Certification handoff package prepared.
