# Repository Documents

The Pages site is a public front door. The full programme pack remains in the
repository root, and root documents are repository-only unless they are listed in
the MkDocs navigation.

Use this page when a link needs to cross from the rendered Pages site into the
canonical repository pack. Do not infer Pages URLs for root files such as
`ARCHITECTURE_OVERVIEW.md`; use their GitHub document links.

## Rule

The Pages site should orient the reader. The repository documents should carry
the full working detail. When a document exists both at the workspace root and
inside `MATH-PROGRAMME`, treat the `MATH-PROGRAMME` copy as canonical for public
documentation.
