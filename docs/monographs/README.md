# Monograph Composition Controls

This directory holds durable composition and continuity controls for Grand Challenge monograph collections. These controls govern exposition, formal-scope honesty, notation continuity, evidence provenance, visual production, and release quality; they do not confer mathematical certification.

## Type Theory — The Grand Unified Theory of Computation

Canonical entry point:

- [`type-theory-series/SERIES_HANDOFF.md`](type-theory-series/SERIES_HANDOFF.md)

The Type Theory package is designed to be sufficient for a fresh composing agent to continue Volumes II–X without access to the originating conversation. Volume I is pinned as a checksummed reference implementation; the series title remains a research hypothesis to be tested across the remaining volumes.
