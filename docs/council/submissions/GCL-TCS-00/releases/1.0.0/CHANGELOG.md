# GCL-TCS-00 1.0.0 release-candidate change log

## From GCL-TCS-00/0.1.0

The proposed `1.0.0` release candidate preserves the substantive charter semantics established by the reviewed `0.1.0` package except where version-bound release controls require explicit changes.

Changes are limited to:

- document-control identity changes from `0.1.0 candidate` to `1.0.0 release_candidate`;
- profile version identifiers change from `0.1.0` to `1.0.0` without changing inherited profile semantics;
- version-1 conformance and record-contract schemas use `1.0.0` identifiers and constants;
- version-1 templates use `1.0.0` identifiers;
- release controls now distinguish historical predecessor, proposed version, current candidate authority, requested authoritative status, G8 review, and G9 admission;
- Section 20 explicitly requires exact-revision G8 review and G9 atomic admission before version-1 authority is effective;
- a migration note, compatibility statement, promotion-candidate record, and release-candidate manifest are included.

No change in this release candidate claims formal ASD-STE100 conformance, mathematical certification, empirical efficacy, novelty, deployment, manufacturing, commercial, legal, credential, safety, GHOS, MATH-CORE, or corpus authority.
