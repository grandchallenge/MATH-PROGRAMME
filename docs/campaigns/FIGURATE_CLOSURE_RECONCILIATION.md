## Verified bounds and exact claims

The WP06 [frozen L240 source record](https://github.com/grandchallenge/MATHSOLVE/blob/main/research/FIGURATE_WP06_L240_README.md) contains the 54-case parameter matrix, the independence/replay regime, runtime environment, source and archive hashes, exact counts and first witnesses. A finite absence is **only a finite absence**; a non-matched timing measurement is **not** a performance speedup.

The WP08 internal [structural proof dossier](https://github.com/grandchallenge/MATHSOLVE/blob/main/work_packages/FIGURATE_WP08_UNIFORM_2ADIC_ADMISSIBILITY_009.md) establishes a necessary-and-sufficient classification of polygonal orders for which **every integer offset** admits **one fixed triple of distinct positive integer entries** that passes *all* binary congruence tests. The criterion is $4\nmid k$ or $k\equiv4\pmod{16}$. The theorem is about local congruence solvability and **does not assert exact Diophantine tuple existence**. Protected proof and tests were merged with independent arithmetic replay, but no claim of external mathematical certification is made.

The [public FIGURATE mathematical explanation](FIGURATE_RESULTS_EXPLAINED.md) provides the pedagogy, and the [source-critical register](FIGURATE_SOURCES.md) distinguishes Type A (polygonal entries / square outputs), Type B (polygonal pair outputs), and Type C (both).
