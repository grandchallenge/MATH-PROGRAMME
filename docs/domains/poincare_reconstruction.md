## Archive purpose

This is a source-normalized reconstruction of the Hamilton–Perelman route, with explicit theorem interfaces, correction ledgers, adversarial guards, bounded topology-event certificates, and a public claim boundary.

It is not an open-problem attack. It does not claim a new proof, an independent analytic verification, a formalized Ricci-flow proof, a machine-checked Poincaré theorem, novelty, or priority.

## Certification boundary

The bounded evaluator checks finite imported event relations and structural reconstruction consequences. It does not certify the imported analytic surgery construction, manifold-level semantic correspondence, or the complete theorem.

## Maintenance rule

No automatic theorem-strengthening Work Package is authorized. Citation correction, documentation preservation, CI upkeep, overclaim repair, and bounded pedagogy may proceed without changing the claim surface.
