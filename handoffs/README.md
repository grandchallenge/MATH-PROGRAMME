# MATH-PROGRAMME handoffs

This directory contains repository-local continuity packages for work sets whose primary deliverable or governing coordination contract is owned by `grandchallenge/MATH-PROGRAMME`.

The generic GCL handoff machinery no longer lives here.

Canonical GCL handoff surfaces:

- constitutional authority: `grandchallenge/INTELLECT:CONSTITUTION.md`;
- canonical handoff contract: `grandchallenge/INTELLECT:governance/handoffs/README.md`;
- copy/paste takeover prompt: `grandchallenge/INTELLECT:governance/handoffs/CANONICAL_TAKEOVER_PROMPT.md`;
- new repository-local handoff template: `grandchallenge/INTELLECT:governance/handoffs/_TEMPLATE/README.md`.

## Placement rule

For a new substantial work set, place its actual continuity state in:

`<TARGET WORK REPOSITORY>:handoffs/<WORKSET-ID>/README.md`

Use MATH-PROGRAMME's `handoffs/` directory only when MATH-PROGRAMME owns the primary deliverable or governing work-package/coordination contract. A cross-repository umbrella campaign may remain here when MATH-PROGRAMME is the governed coordinating owner; component implementation state should remain local to each component repository.

Do not use this directory as a GCL-wide control repository merely because historical handoffs were once centralized here.

## Existing packages

Existing packages remain durable historical and live continuity records. Their location does not enlarge MATH-PROGRAMME authority and does not supersede the canonical INTELLECT handoff contract.

Before taking over an existing package:

1. read `grandchallenge/INTELLECT:governance/handoffs/README.md`;
2. re-fetch protected INTELLECT and MATH-PROGRAMME state;
3. read this repository's `AGENTS.md` and exact domain governing instruments;
4. read the work-set package and its authoritative pointers;
5. produce the canonical preflight before mutation;
6. proceed under the live delegated authority and exact reserved boundaries.

MATH-PROGRAMME execution disciplines such as `MP-STREAMLINED-EXECUTION-001` and `MP-SUBSTANCE-FIRST-EXECUTION-001` continue to apply within their admitted mathematics-domain scope. They do not replace the INTELLECT constitutional chain.
