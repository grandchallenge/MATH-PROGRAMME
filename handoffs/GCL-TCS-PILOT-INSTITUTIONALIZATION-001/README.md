## Core operating rule

For routine bounded work use:

`classify material closure -> run affected checks -> exercise delegated disposition -> protected merge -> protected readback`

Do not manufacture Human Steward or Referee gates. Require those actors only where the controlling instrument materially reserves the transition.

When two procedures protect the same material boundary equally well, prefer the one with fewer gates, fewer reruns, fewer actors, and less persistent machinery.
